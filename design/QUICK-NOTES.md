# 随手记 / Notes

2026-11-28 · 本轮实现规范；服从 PRODUCT_CONSTITUTION.md。

## 设计决定

统一记录入口，保留普通记录与待办的语义。使用已有中性玻璃容器与全局宽度、圆角，不叠加第二层卡片，不加模块标题。输入正文是主体，鼠标悬停或编辑时才显露新建、转为待办、仓库等工具。以系统字体、原生文本编辑器和输入法完成文字编辑。

| 状态 | 呈现与交互 |
| --- | --- |
| 空闲 | 约 44 pt 高的一行「记下一点想法…」，点击即输入；无空列表、统计或标题。 |
| 书写 | 原地展开。自动保存每次文字变更；自然换行；长文在输入区滚动。新建收起前一条并保留历史。 |
| 待办 | 完成圆圈＋可编辑正文。增加待办立即建立持久身份，未按回车也不丢输入。 |
| 共存 | 正文和待办共用一个连续容器；只有两者同时存在时才出现细分隔线。 |
| 较多内容 | 模块高度有上限；内部滚动保留访问。屏幕空间不足继续沿用宿主收纳，不另造宽度系统或挤小窗口缩略图。 |
| 完成 | 立即持久化，短暂打勾反馈后撤下；仓库可取消完成。 |
| 资料管理 | 唯一主窗口的随手记仓库：全部／记录／未完成／已完成，搜索、阅读、修改、复制、删除、转换。侧栏入口定位到当前记录。 |

`quick-notes-states.svg` 是状态设计稿，不是原生截图；完整组合的最终视觉判断以本次云端运行截图为准。初次自审删除了独立待办标题、空列表和常驻保存按钮，合并为一个容器。现有语音、截图、歌词面板保持结构。

## 数据与生命周期

沿用 SidebarNotebook 与 sidebar-notebook.json；所有数据归 Nearpane。记录拥有稳定 ID、正文、类型、创建／修改时间及完成信息。转换不复制内容或生成新 ID。旧单份 memo、tasks 连同计算草稿、单词本完整迁移；旧任务保留 ID，旧格式没有逐条时间，采用原资料文件的修改时间作为迁移基准；这不代表能够追溯每条记录真实的创建或完成时间。首次迁移保留原始字节副本。

写入采用原子替换；每次文字变更落盘，不依赖稍后执行的定时保存。保存失败保留内存文本并明确重试；退出前重试未落盘内容，仍失败时留在应用中。损坏资料不自动覆盖；提供恢复最近副本的显式入口。停用或移除能力不清资料，仓库照常访问。

原 memo 模块 ID 作为统一模块的稳定身份；旧 memo/tasks 配置合并到它们原来最靠前的位置，启用／固定意图取并集，其他模块相对顺序不变。新安装直接启用随手记；已有用户两者都关闭时继续关闭。

## 范围与验收边界

第一版纯文本、本地资料；不接 Apple Notes/Reminders，不增加文件夹、标签、附件、提醒、AI 或独立 App。复用当前 main 的左右侧栏与原生全屏临时工作台。当前主线 SurfaceEdge 只实现左右，不能把结构兼容称为上下四边原生验收通过。本轮不重写全局布局或 Spaces 引擎。

验收证据必须分别标注：设计稿、真实运行的原生界面、测试内容夹具、系统级真实行为。合并资格与正式发行资格分开记录。
