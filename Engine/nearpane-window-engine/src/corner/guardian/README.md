# Corner recovery handoff

This separately signed fixture Guardian retains one ordinary AX window before the signed test Host parks it. The ordinary build does not launch the helper. The independently supervised crash trial uses a fresh private directory and the same C request identity, original geometry and durable intent on both sides. The existing Swift Host journal remains the owner of product transactions. Production journal integration and qualification require separate review.

The Host opens a new owner-only ledger and starts the Guardian over inherited anonymous pipes. It fsyncs each fixed-sized record before sending those exact bytes. The Guardian binds its kernel parent PID, birth and code identity, the enrolled child application, private kit code hash, display and native Space. It retains the exact AX object and checks its AppKit role plus AX and WindowServer geometry before it acknowledges preparation. The second record must correspond to the same intent, group, member, lifetime, generation, epoch and input counters. The Guardian verifies the real parked postimage twice and acknowledges it. Neither acknowledgement issues a write.

Only EOF and a kernel exit event for the original Host together can arm recovery. The same retained object, signed fixture process, geometry, original display and Space, complete journal, secure-input state and HID counts are checked again at the existing single AX setter. A confirmed restore requires two original-frame readbacks. A restarted Guardian has no original AX reference. An unsealed postimage, a living Host, a reused identity, a user change, an unknown setter outcome or missing permission cannot trigger a replay. Unresolved records remain in the receipt directory.

The disposable supervisor records the sacrificial Host's actual SIGKILL, then independently checks that its two child applications survived and kept the original geometry and counters. It sends one test gesture to the exact restored fixture window and checks which document received the complete gesture. Both test owners close themselves on teardown. Receipt files include the shared binary ledger, the original Host request, the Guardian decision and the supervisor's independent result. Ad-hoc fixture signatures and a hosted session do not establish qualification of a shipped helper.

Run the complete hosted fixture from the repository root with `scripts/acceptance/window-engine/corner/run-hosted.sh NEW_OUTPUT_DIRECTORY`. The optional `--scope-only` mode reads only display and ordinary Space identities. The `--build-only` mode compiles and signs the artifacts without opening fixture windows. The actual crash drill uses a clean phase after a complete initial A→B→C→A circle and verified teardown. All operational modes use a fresh output directory.
