# HOLDSNOW 产品影像语言 · Nearpane v3

以“音乐继续，手上的事情也继续”为叙事中心。先听见歌曲、看见原封面和歌词，再切到阅读；鼠标移入时用一句话说明控制。Nearpane从开场即出现，最终品牌落版统一收束。Riftlet在后段作为可组合功能，控制其说明篇幅。

## 画面

使用获授权的暖灰海岸桌面和真实macOS窗口。主产品靠右上，顶边与右边留实际系统余量。显示产品时不更换图标、不重绘控制条、不修饰成不存在的交互。细节镜头允许等比例裁取真实界面、加入编辑背景与阴影，记录来源与变换。

纸色`#F6F6F2`、墨色`#222D2D`、次级灰`#5C6A69`。主片沿用真实海岸的灰青与柔和暖色，不叠加装饰粒子或发光。英文品牌Inter；中文Noto Sans CJK SC。均保留字体授权。

中文横版主标题在1080p为56px粗体，比v2的26px更醒目。标题避开应用正文与右上卡片；需要时加22px来源或品牌说明。片尾品牌144px，宣传语44px，官网30px。

## 卡片规则

**等宽不等于等高。** 每个模块采用自己的真实内容布局。Riftlet空态76pt、一张截图后144pt，歌词卡192pt基准；统一摄影比例，不单独缩放内部图标。换位与展开遵循实际录屏时序，不为了动效顺滑添加未实现的中间状态。

## 节奏与声音

原歌曲贯穿，六句短解说之间留出音乐空间。解说回答当前镜头的一个问题，不逐项念说明书。少量短句使用淡入淡出，镜头以真实操作推动；最后以600ms纸色过渡进入品牌落版。

保留原歌曲和专辑封面的署名。公开安装包未核验时使用“访问官网 · 产品预览”；不以视觉包装替代真实发行进度。
