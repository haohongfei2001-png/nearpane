隐私说明

LyricTile 是 HOLDSNOW 的独立 macOS 歌词工具，不需要账号，不包含广告、遥测或向 HOLDSNOW 上传播放记录的服务。

播放器信息

为显示歌词和控制音乐，应用读取播放器提供的曲名、歌手、专辑、时长、播放位置、状态和封面。Apple Music 和 Spotify 的自动化权限按实际需要由 macOS 请求。常规歌词功能不需要麦克风、屏幕录制、辅助功能或完全磁盘访问。

在线歌词

在线查找默认开启，欢迎页会说明，可在设置中关闭。开启时，当前歌曲的标题、歌手、专辑和时长会发往 LRCLIB。服务端也会收到建立连接所需的 IP 地址和识别应用的 User-Agent。LyricTile 不发送原始音频、本地歌词文件、账号凭据或完整播放历史。第三方服务按其自身条款处理请求。关闭后不再发起新的歌词请求，已保存的歌词仍可使用。

保存在本机

歌词和手动绑定保存在 ~/Library/Application Support/HOLDSNOW/LyricTile/，偏好保存在 macOS 应用偏好中。自动缓存最多 64 MiB、256 项，期限为 7 天；手动导入和明确绑定的文件不按自动缓存规则删除。清除缓存不会删除这些文件和其时间校准。卸载应用不会自动擦除歌词资料。

封面、更新和诊断

播放器可提供本地封面，Spotify 路径也可能从其提供的地址获取封面。检查更新会连接配置中的 GitHub HTTPS 更新源和下载地址；自动检查初始关闭。下载平台会收到正常连接信息。应用不运行独立分析服务。

主动导出的诊断可能包含曲名、播放器版本、播放时间、系统信息和本地路径，只保存到用户指定的位置，不自动上传。分享前请检查内容。

歌词内容

歌词、录音和封面归各自权利人。LRCLIB 开放 API 不代表每首歌词都有版权授权。LyricTile 不附带第三方歌词库，也不宣称拥有或转授内容权利。可以查看当前歌词来源，或导入自己有权使用的歌词。

联系与页面数据

隐私问题可通过 GitHub issue 提交。请勿在公开页面附私人记录、凭据或未检查的诊断原件。此产品页无广告、分析脚本或追踪 cookie；网页和下载托管方会接收正常的网络请求信息。
