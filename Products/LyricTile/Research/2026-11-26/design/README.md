# LyricTile 高保真设计

主入口：LyricTile-Design.html。全部图稿使用原创排版样句与生成封面；这是明确标注的视觉/交互设计原型，未连接真实播放器。它不证明 macOS 窗口行为、媒体控制、歌词覆盖率或实时同步已实现。

HTML 可直接本地打开，提供方向比较、真实尺寸词页、明暗/复杂背景、状态排版、引导和整体桌面组合。点击顶部状态即可切换，鼠标进入词页显示控制。触屏可用“显示控制”按钮查看同一状态。

01 为最终选择「雾白词页」，02 为「封面回声」，03 为「双行字幕」。比较稿保持实质性结构差异，不将三种皮肤当成三个方向。

图标：app-icon-concept.png 为生成的材质概念图；lyrictile-symbol.svg 是独立绘制的确定性符号母版。正式图标按母版与材质规范在 Icon Composer/Xcode 中重建，不能把生成图的噪声边缘直接当发布资源。图标白色面板内的三条文字笔画与单个阅读游标，和 HOLDSNOW 的白玻璃/墨色/点语言一致。


## 动效补充

`LyricTile-Motion.html` 是可重播的独立设计样本：固定208×272外框、线性字级遮罩、220ms换句及暂停/Reduce Motion。原创样句与时间编排只用于视觉评审，不能进入产品真实数据层或计入播放器验收。
