## 原专项决策记录

1. **Native 优先。** Virtual 保留已有定义，本轮不以虚拟工作区、隐藏窗口或应用切换冒充系统 Spaces。
2. **复用成熟实现。** 主切换候选为 InstantSpaceSwitcher v3.1 的 ISS 小核心；yabai 最新已核对实现作为技术对照和迁窗候选。具体 pin 见 DECISIONS。Codex 负责适配和结果核验，不让用户安装、配置多套窗口管理器。
3. **必须接到实际侧栏。** 核心链是“生产 UI → 生产动作服务 → 系统状态到达 → 精确窗口可输入”；不能以测试程序代替产品发起动作。
4. **空间行与窗口点击分开。** 空白/背景点击切空间；具体窗口点击切至它所在空间并精确聚焦；明确拖动迁移窗口。旧“窗口缩略图不可单击激活”的条款在本专项由此更新。
5. **默认保留原生式平滑过渡。** ISS 瞬切只证明真实空间可切换，不自动证明原生动效达标；遵循系统减少动态效果，用户不承担速度/后端/校准设置。
6. **正常授权后直接工作。** 不要求用户配置快捷键、关闭 SIP、安装 Dock 注入组件或逐次确认普通窗口切换。OS 强制的首次权限确认如确实需要，由账户所有者完成一次最小动作。
7. **验收由 Codex 完成。** 准备测试空间、合成内容和实际应用窗口，自行驱动、观察、修复、复测、清理；用户不充当测试员。
8. **完整目标保持。** 空间切换、精确选窗、真实迁窗是核心；既定平铺、默认新窗归属、空空间清理、多屏、全屏和恢复分别验收，不以基础路径通过替代整体完成。
