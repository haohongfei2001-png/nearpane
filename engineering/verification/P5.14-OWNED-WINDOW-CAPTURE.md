# 单个后台测试窗口的 AX 身份和像素读回

2026-11-17，Apple Silicon，macOS 27.0 build `26A428`。本次只创建一扇无正文、小尺寸且不能成为 key/main 的 AppKit 测试窗口。已具备辅助功能和屏幕录制权限。对其他应用只比较前台进程是否保持一致，未记录其身份。

| macOS 实际读回 | 结果 |
| --- | --- |
| 测试对象 | 独立开发签名 `.app`，`LSUIElement=true`，在 `.accessory` 策略下执行 `NSApplication.run()`。启动回调之后才将自建窗口 `orderBack`。 |
| CG | owner PID 与本次进程相符，窗口号 `8096`，layer 0，在屏。frame 为 `(675, 443, 120, 104)` pt。 |
| 外部 AX | 独立子进程检查父程序可执行文件后，读取这一个进程的窗口。`AXWindows` 返回成功，共一扇，frame 与 CG 完全相同。 |
| 窗口号 | `AXWindowNumber` 返回 `-25205`（attribute unsupported）。项目已有的只读 `NPReadAXWindowNumber` 在允许的系统 build 上取得该窗口号一次。标准角色与子角色的联合检查未通过，因此这扇后台测试窗没有取得普通用户窗口准入。 |
| 图像 | `SCShareableContent.currentProcess` 返回自有窗口。以 PID 和窗口号限定的单窗 `SCContentFilter` 交给 `SCScreenshotManager`。返回 120 × 104 像素。转为明确的 sRGB RGBA8 后，左色块 `[31,192,76,255]`，右色块 `[205,31,153,255]`，与绘制时的目标 `[31,191,77,255]` 和 `[204,31,153,255]` 各通道误差不超过 1。 |
| 焦点及清理 | 观察期间没有前台进程变化通知，动作前后前台 PID 相同。测试窗口的受检状态始终未成为 key/main。窗口 `orderOut`、`close` 后不再可见，测试应用正常退出。 |

规范化像素 SHA-256 为 `b288bf17cafc733648bbd1b31c84da2c25b9ffc1e33564ba893d3011c1a01128`。签封测试程序 SHA-256 为 `dc81d8d1164d0bb70d2918b7b5b4ec8123e1ad1ef82021697b75e436864bda53`。只保留颜色、指纹和测试对象几何，未保存图像。[本机运行收据](../../build/verification/p514/registered/appkit-run.json)

早先的无 AppKit 事件循环程序使用 `.prohibited`。在该条件下，独立 AX 读取返回 `-25204`，CG 与单窗截图接口仍返回数据。两次对照说明需要在正常事件循环中验证 AX，且同一窗口的可见位置不能代替正向窗口号。这次验证覆盖单窗身份读取与单窗像素供应；普通用户通过系统选择器选窗、生产 Host 绘制并在授权撤销时清除图像的端到端现场验收仍待完成。

## 复现条件

在本人明确许可的本地图形会话中，从仓库根目录运行。程序只向自己新建的窗口绘制两个纯色块。以下命令将测试包写入临时目录，不安装到应用程序目录。仅在已有相应权限时读取 AX 或捕获图像，未授权的项目会在回执中保留缺失状态。

```sh
probe_dir=$(mktemp -d /private/tmp/nearpane-preview.XXXXXXXX)
app="$probe_dir/Owned Window Preview.app"
mkdir -p "$app/Contents/MacOS"
cat > "$app/Contents/Info.plist" <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<plist version="1.0"><dict>
<key>CFBundleIdentifier</key><string>org.nearpane.acceptance.OwnedWindowPreview</string>
<key>CFBundleExecutable</key><string>OwnedWindowPreview</string>
<key>CFBundlePackageType</key><string>APPL</string>
<key>CFBundleVersion</key><string>1</string>
<key>CFBundleName</key><string>Nearpane Owned Window Preview</string>
<key>CFBundleShortVersionString</key><string>1.0</string>
<key>LSUIElement</key><true/>
<key>NSPrincipalClass</key><string>NSApplication</string>
<key>LSMinimumSystemVersion</key><string>15.2</string>
</dict></plist>
PLIST
xcrun clang -I Sources/CReadOnlySpaces/include -c Sources/CReadOnlySpaces/ReadOnlySpaces.c -o "$probe_dir/reader.o"
xcrun swiftc -parse-as-library -import-objc-header Sources/CReadOnlySpaces/include/ReadOnlySpaces.h scripts/acceptance/owned-window-preview.swift "$probe_dir/reader.o" -o "$app/Contents/MacOS/OwnedWindowPreview"
codesign --force --sign - "$app"
codesign --verify --strict "$app"
"$app/Contents/MacOS/OwnedWindowPreview"
```
