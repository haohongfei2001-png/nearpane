## 成功、拒绝与中断

以下使用隔离 SQLite、合成文件和真实文件系统。SIGKILL 的对象是迁移子进程；磁盘写入拒绝与断电是不同实验。

| 场景 | 判据与结果 |
|---|---|
| 1. 空资料 | 空来源可导入，未选择的类别保留当前资料；首次启动不选旧版，保持空白。 |
| 2. 已编辑文字 | 比较记录、修订、手工首选修订、编辑草稿和冻结文字。跨旧版保留文字，原始录音留在来源；本版未选文字及本版回退时另用合成音频文件核对音频块及 SHA-256。 |
| 3. 多张截图 | 5 张图逐一对照 UUID、排列、媒体摘要及操作历史；数据库重建后重新执行完整性和外键检查。 |
| 4. UNKNOWN、FAILED 与旧 claim | 对照资产、操作、尝试及历史状态；已尝试资产被禁止重放，跨替换和回退仍受限。旧输入不能重新武装，新的未使用资产仍有正常入口。没有新增外部输入或派发。 |
| 5. 迁移中强退 | 在两份备份落盘后、代际目录已发布后、活动索引已发布后三处实际 SIGKILL。新进程恢复两次：前两处留在原代际，第三处核验已发布代际；第二次恢复不重复切换。 |
| 6. 写入失败或资料残缺 | 注入 ENOSPC，并用系统文件大小限额取得实际写入拒绝；另测缺媒体、损坏备份及残缺 WAL。均未把残缺代际发布。有完整已提交 WAL 的资料则保留下来。 |
| 7. 未知 schema | SQLite 版本不符，或版本号相同但表结构指纹不同，拒绝发布。来源保留。 |
| 8. 回退 | 实测本版备份回退、旧 App 读旧副本两条路径。回退后不以旧窗口号或外部草稿绑定恢复动作。 |
| 9. 重复导入 | 同一来源、范围和有效代际返回已有结果；来源改变后旧预览令牌被拒绝。 |
| 10. 两个写入者 | 另一进程持有资料锁时拒绝切换，同时核对旧版领域锁。Host 独占租约阻止两个版本同时使用同一新容器。 |
| 11. 显示器身份变化 | 在签包中核对离线 UUID `5CC84B1F-E438-4D64-83C5-A2DA2F79F4FD` 及其 20 × 20 pt 尺寸；保留该屏配置。没有拔插实体显示器或改变系统设置。 |
| 12. 未完成窗口事务 | 来源存在未解决窗口恢复事务时拒绝切换；可导入的设置保留布局意图，但自动管理关闭，过期 PID、CGWindowID 和操作许可不能继承。 |
