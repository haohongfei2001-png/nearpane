用 Finder 双击 [Nearpane P5.1 Alpha.app](</Users/hhf/Applications/Nearpane P5.1/Nearpane P5.1 Alpha.app>)。从菜单栏打开「设置 → 尺寸与呈现」，选择主驻留显示器，启用「显示精简工具状态条」，选择允许的工具和角落。默认关闭。确认原生全屏后，点击条中的语音或图片图标才展开工具；关闭按钮只收起工具。拖动移动手柄可以保存本显示器浮层位置。副屏作为 Space-only 使用时只收起自身普通面板。

## 系统能力边界

| 能力 | 本次裁决 |
|---|---|
| 从实时桌面观察辨别原生全屏与普通 Fill；同屏抑制/恢复普通面板 | 已接入 Alpha。权限、矩形、窗口归属或来源不确定时，工具收起并安全降级。状态机和归属反例已验证。实际第三方全屏系统过渡待验。 |
| 自动恢复 Workspace/窗口 | 普通面板按最新每屏 Docked/Floating 配置恢复。托管过的兼容窗口必须有独立来源、身份、几何及持久日志见证。新读取进程产生的 AX 元素标识不能提供跨进程的持续身份证明，因此真实全屏往返可能保持布局恢复挂起。 |
| 全屏应用获得全屏、状态条覆盖、系统自动回来源、主副屏联动 | **PENDING**。本轮真实全屏进入 0 次、真实 Space 切换 0 次。需要在确认不影响日常主屏的无人使用图形环境中，对唯一自建全屏窗口单独验证。 |
| 真实录音／真实截图／ChatGPT 上传 | 浮层打开和收起复用原领域；本轮未执行这些外部输入。P5.0 的一次性输入保护和未确认结果处理继续有效。 |
| 未授权 Space 动作和普通窗口接管 | Native Space 创建、切换、跨 Space 移窗及 Virtual 停放继续关闭。普通工作窗口继续排除在授权写入范围外。 |
