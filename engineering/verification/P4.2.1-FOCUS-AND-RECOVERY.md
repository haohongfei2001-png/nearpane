# P4.2.1 焦点与恢复实机收据

**本次冻结试验在已执行动作的采样边界通过焦点检查。** 原 P4.2 焦点中止的历史原因没有新数据可供追溯。Virtual 恢复没有成功，副屏内位移的 SIGKILL 恢复成功，两者分别判定。

独立于调度控制器的夹具监测 NSWorkspace 前台 PID，并向该 PID 读取 AXFocusedWindow，只比较同一 AX 元素和 PID。未读取私人窗口标题、文本或像素。夹具另行记录自身 active、窗口 CG 编号、key/main、firstResponder 的进程内不透明标记，订阅应用激活/去激活及窗口取得/放弃 key/main 的通知。单调时钟关联动作前后检查点。[观察器](../window-lab/Sources/NearpaneFixtureWindows/FocusStudy.swift) · [无 GUI 回放器](../../scripts/acceptance/replay-parking-study.py)

| 现场动作 | 独立读回及结果 |
| --- | --- |
| 普通移动、缩放、WorkRect 重排 | 首窗位移一次、双窗 Docked 四次分步写入、返回原位四次分步写入。AX/CG 确认几何，前台 PID 和 AX 焦点一致 |
| 显示与隐藏 | 实际面板显示、隐藏、再显示、展开、收起、关闭工具区和再次隐藏；每次另查面板及普通窗，均无焦点越界证据 |
| 安全拒绝 | 最小尺寸拒绝、排他租约冲突、未确认的最小化与其恢复拒绝均保留原始错误。主动取消没有独立的本轮实机结果 |
| 副屏内 SIGKILL | 确认前强杀确切的控制子进程。W1 从 (−681, 1034) 真实移动至 (−667, 1043)，AX/CG 已读回，日志 confirmed 仍是原位。新控制器校验同一代际，一次写回原位，重复恢复为零写入。两次恢复均有真实读回 |
| Virtual | 首次最小化后恢复判定失败，未执行虚拟切换及最小化/反最小化两处 SIGKILL。夹具退出清理单独记录 |

回放核对 111 个时间有序样本、29 对命令检查点。前台 PID 始终等于基线；所有样本均读到同一前台 AX focused window，夹具未激活，自有窗口均未成为 key/main。每扇在册窗口的第一响应者标记稳定，激活/去激活和 key/main 通知数均为零。最大采样间隔 159.1 毫秒。该结论限这次运行及其采样分辨率；无权推断未采样的极短第三方焦点往返。私人前台应用的第一响应者内容未读取。

初次启动曾遇到编译失败后残留的旧缓存成品，登记一扇窗口后因无焦点检查点中止，清理确认一个 CG 编号消失。该运行零 AX 写入、未计入结果。随后修正编译并核对成品，最终监督器还在登记前检查协议与能力。交付版本的拒绝复核仅运行 preflight，未启动窗口进程。
