# P5.8 随包运行环境与领域更新

本轮基线为 `1134652e1b2da2f9aeaa2a5383daf1022363a524`，使用唯一 checkout 和 `implementation/host-foundation-20261109`。任务包含消除个人 Alpha 运行时对开发工具 Python 的依赖、采用兼容的第一方领域更新、隔离资料升级回退和更新统一安装包。

## 实际运行路径

`BundledAutomation.executable()` 按当前 App 内的五项 SHA-256 检查助手、标准库及三个脚本，并核对助手签名。Settings 的资料预览、导入、回退和启动时的迁移恢复均通过该入口。兼容窗口管理服务通过同一助手启动。普通窗口管理原有的原生控制器继续负责 AX 写入。

`Contents/Helpers/NearpaneAutomation` 静态链接官方 CPython 3.14.10 和所需扩展，标准库只从 `Resources/Automation/stdlib.zip` 加载。它只接受 `profile`、`workrect` 和自检入口。隔离解释器关闭 site、环境路径和字节码写入。缺文件、指纹不符或验签失败会显示恢复完整安装包的错误。

底层动态依赖为 macOS 的 CoreFoundation、libSystem、libsqlite3、libz。来源 XZ 的官方 SHA-256、固定源码日期、编译器与 SDK 元数据、PSF/HACL/SQLite 等声明均进入包内。每次构建校验来源归档和缓存内容，离线缺包及内容损坏均拒绝。

开发机仍通过 Swift、Python 和构建工具编译工程。用户的安装包支持既有的 Apple Silicon、macOS 26 起的产品范围。辅助功能、截图目录、麦克风和浏览器等权限仍按原主体和用户操作核对。

副屏 Settings 使用同一禁止开发工具的沙箱，实际按压预览、确认导入及退出控件。各检查点窗口 frame 和前台 PID 一致，进程正常退出，新 Host 重开后取得一条文字记录和五张图片，来源指纹一致。[Settings 原生操作](../../build/verification/p58/settings-import.json)
