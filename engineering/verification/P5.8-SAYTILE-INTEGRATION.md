- `SpeechResultAccumulator.swift` 保留 Apple 在最终时间戳单独送达的中文标点和 finalization watermark。相同标点重投递不会重复追加，未归属已定稿范围的零时长文字不会插入。中文标点前的空格按上游规则处理。

## Nearpane 接线

`NearpaneManualInsertion.swift` 在一次用户手势建立的固定输入目标中透传领域需要的全文见证，目标失效时拒绝继续读取。明确的 `AXTextWriteTimeout` 允许同一目标进入只读确认，不重新派发。普通 verify 前后都重验本次手势目标。界面、资料和领域实例仍沿用现有路径。

采用的 RC2 识别配置在录音开始冻结唯一语言专家，不再把界面语言当作讲话语言。当前 Nearpane 已选本机模式保持本机，用户明确批准的 API 模式继续使用该资料的具体专家和 GPT-6 配置。重试既有录音仍遵循原资料级授权和原音保留。
