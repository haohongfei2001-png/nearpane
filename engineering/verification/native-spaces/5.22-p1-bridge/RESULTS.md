# P1 迁窗 ABI 与读回

5.22（90）生产迁窗状态为 **DISABLED**。本次把 `5217dbf` 的准备工作接入 `82a7c467` 基线。当前 Mac 的只读运行时元数据显示，初始化签名为 `@32@0:8@16Q24`，提交签名为 `v16@0:8`。生产入口在创建系统对象前拒绝请求。实机往返仍为 **NOT_RUN**。[离线收据](bridge-abi.json)

同一份 Objective-C 适配器分别以 ARC 和手动引用计数编译。每轮只有两个模拟操作获得实际调用。第一个接受 12 次并发竞争中的一次提交，第二个在调用时抛出异常，返回结果未知并拒绝重投。测试还核对了类型签名、不可变的单窗口数组和对象的释放时机。两个调用边界记录到的系统操作创建和系统迁移请求均为零。

迁窗助手持有已准备的对象直到终态。核验时逐一比较目标的实际 AX 引用、进程出生和同应用兄弟窗口，再对照系统的窗口归属与每个桌面的成员清单。缺失清单、额外归属、重建窗口、过期请求和兄弟窗口变化均不能确认到达。Swift 测试使用本地不透明引用及固定读数。真实安装版的 Space 和窗口归属仍须在 P0 通过、P1 取得正式实机许可后独立验证。

在 macOS 项目根目录复算收据。

```sh
python3 scripts/acceptance/native-spaces/check-move-abi.py
```
