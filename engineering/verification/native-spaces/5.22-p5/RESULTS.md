# P5 布局、恢复与性能准备

**此次为离线验收。** 37 项 Swift 测试和 6 项性能采样器测试通过。生产窗口几何、原生对照、五批预热后时延、系统掉帧及真实唤醒恢复时间均未在本轮测量。[本轮逐项收据](offline-qualification.json) · [早期 30595b2 采样器记录](harness.json)

- 生产布局规划器在带负坐标、宽高均为奇数的实际可用区模型中，逐个核对 1、2、3、4、8 个窗口的身份和整数边界。既有用例覆盖第 9 至 17 窗、最小尺寸、用户自定义分割、原生 Split View 的双窗身份以及独立和共享显示器模型。
- 生产 Host 使用可延迟的离线读数模拟休眠和两次锁屏。休眠前的读数、第一次解锁后又跨过第二次锁屏的读数均被丢弃，最终只发布最后一个新版本。真实锁屏、唤醒、重连和第二块屏幕仍待实测。
- 性能采样器针对 20 次预热、5×20 次产品操作和 20 次系统参考，检查固定顺序、真实落点、唯一正式 Host 操作及三个投递阶段。缺项、重复、反跳、未决或失败记录保留。只有整组有效时才给出 P50/P95/P99。CPU 和物理内存采样分别核对 Host 与每个 helper 的出生、父进程及计数单调性。内核 CPU 单位用测试进程自己的独立 CPU 时钟复核。
- 当前生产切换能力 `canSwitch` 为关闭，性能入口在原生参考和产品动作开始前返回。旧版三桌面行入口需要能按冻结合同核实的正式控件；后续窗口卡基准还需完成 P0 及同动画原生参照。此前真实安装的一分钟隐藏与恢复有独立收据。实际全屏和重启仅获部分结果，多屏与双窗原生 Split View 仍阻塞。[已安装的一分钟收据](../5.22-90-active-display-previews/installed-hidden-minute/result.json) · [已安装的生命周期收据](../5.22-90-installed-contract/runs/final-lifecycle/results.json)
