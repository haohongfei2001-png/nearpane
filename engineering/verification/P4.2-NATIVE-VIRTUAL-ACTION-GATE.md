# P4.2 系统动作专项准入

产品权威为 `8563501f6bc819484520dd189f0c3e989053e8fc`。P4.1 已具备只读 Host、布局计算、独立动作门槛与合成恢复收据。Native 的系统写能力和 Virtual 的真实窗口接管仍未开放。完整核验证据见 [P4.1 工程收据](P4.1-WORKRECT-TILING-VERIFICATION.md)。

## 一次确认的实验范围

只使用独立登录的 macOS 测试账户或专用设备、已标记的 Nearpane 测试包、专用合成窗口生成器、指定副屏和测试资料目录。开跑前记录 OS build、代码身份、签名/哈希、显示器 UUID、窗口 PID/启动代际/CG 编号/AX 元素、已有 Spaces 设置和初始焦点。窗口只提供编号、纯色色块及已知最小尺寸。保留系统桌面、用户应用及个人内容的原有状态。

| 实验 | 拟授权的对象和动作 | 必须实测的终点与失败处理 |
| --- | --- | --- |
| AX frame 与 WorkRect | 给指定测试动作进程辅助功能权限，仅移动或缩放白名单普通窗。在副屏验证负坐标、旋转、Docked/Floating、Fill、1–8 及 9–17 窗 | 独立 CG/AX 读回每窗实际 frame，逐窗检查最小尺寸、覆盖、遮挡和显示器。隐显/收起次数不能增加窗口写入计数。部分执行失败按日志逐窗还原，核对焦点 |
| Native 切换、归属与焦点 | 只切换自建且已见证的普通测试 Space，整行切换、一次跨 Space drop；仅必要时恢复先前的测试窗焦点 | 来源、目标及回执绑定同一操作和新鲜身份。实际 membership 唯一，前后台 frame 均有回读。若 separate-Spaces=false 可能带动用户主屏，转专用登录环境验证 |
| Native 创建及清理 | 允许创建临时测试 Space，允许迁出、回收本轮刚腾空且经过完整成员复查的测试 Space | 普通新窗与溢出分别验证；能力不足、已达系统上限、创建失败后的安全分割。保留仍含最小化、未管理、全桌面驻留成员的空间。活动空间及系统保底桌面受保护，清理后再读系统清单 |
| Virtual 接管与恢复 | 在同一标记窗口集合上模拟应用新窗、逻辑工作区、跨组、屏外停放、退出、主动重新启动、仅强退测试管理器 | 日志先于写入；逐次回读成员、frame、可见性和层序。覆盖强退在写入前后、权限撤销、对手管理器、窗口重建、显示器失效。自动改动撤销，自定义意图映射完整可用区，排除对象不被接管 |
| 真全屏与浮层 | 仅合成应用进入/退出原生全屏。允许点击测试状态条、手动拖动浮层、测试恢复来源空间 | 普通 Fill 继续受 WorkRect 限制；真正全屏隐藏完整侧栏，浮层只经人工动作展开。回源和恢复均需新回读。校验部分/模糊证据时保持受限 |
| 两种模式互斥 | 仅在以上对应动作已分别取得本机证据后，在设置中转移测试集合调度权 | 保存两套身份和受影响窗口，核对权限、领域未完成工作和日志；完整恢复旧所有者后才能提交新模式。模式切换期间不产生附加、发送或录音状态变更 |

此前的单窗口取证授权限已标记副屏夹具。需要新 TCC 主体或变更权限时由设备所有者在系统设置中批准，记录准确主体。几何、成员和大部分恢复检查可只读元数据。仅在获准取证窗口内测试材质及真实动效。上述实验不需要麦克风、语音识别、Chrome 登录、自动化浏览器、全桌面录制或 Mission Control 设置变更。

## 执行与回滚

1. 固定测试会话、显示器、许可动作、成员身份和超时。记录完整初始可访问状态，包括焦点、显示器、原生/逻辑空间、窗口 frame、可见性、层序、排除和自定义布局。中途新增白名单对象需要新的受控登记。
2. 每个不可逆操作前再核验 token、revision、能力、目标所有者、完整成员及可恢复性。真实 Native 创建/删除、跨空间移窗和精确焦点恢复需要各自独立、匹配 OS build 的适配器证据。
3. 用户活动更改、失去权限、目标重建、其他管理器争用或主屏将被影响时停止写入。已开始的操作按原记录逐一回读；冲突项保留日志，不能自动改写第三方新状态。
4. 先恢复窗口可访问性，再清理本轮创建的空测试空间并核对来源焦点。异常终止后由新测试进程独占日志，完成恢复再重新从当前观测接管。不得强杀用户应用。
5. 仅当两种模式分别完成动作、失败、退出与恢复矩阵，才考虑开放对应设置。P4.0 见证、合成 SIGKILL、构建通过和截图本身均不授予系统动作能力。
