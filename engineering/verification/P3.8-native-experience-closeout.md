## 语音

**PIPELINE TEST 通过。真实本机中文识别为 ENVIRONMENT BLOCKED / USER ACTION REQUIRED。** Host 的麦克风授权值为 3（authorized），语音识别为 0（notDetermined）。中文转写器受支持，系统资源状态为 `supported`，尚未 `installed`。系统报告六个音频设备，其中两个具备输入通道，分别为蓝牙和机内输入；没有可确认的静音测试输入。只查询状态，未创建录音设备、申请 TCC 或安装系统资源。

用本机 Tingting 仅向文件合成一句固定中文，得到 38,210 帧 16 kHz 单声道 PCM。把样本及尾部静音送入固定 Saytile 的真实 AudioRing、CaptureWorker、转换器、WebRTC VAD 和 PCMJournal。VAD 依次报告有声与安静，临时库 Recording `D969126D-D86D-4193-B220-F96931D9BFEB` 保存 49,600 帧（含保留静音）。识别服务关闭，状态 `queued`，无 Recognition Attempt、terminal 或 final。另有可重复的合成波形回归检查静音分段、持久化和零丢帧。[PCM 回归](../../Tests/NearpaneVoiceTests/PCMPipelineTests.swift) · [本次摘要](../../build/verification/p38.aUD05A/pcm-pilot.json)

Apple 的进程音频 tap 能取特定输出，需自己的系统音频采集授权和路由；本轮没有已获准且能让 AudioController 的输入节点读取该音源的设备。离线渲染产生的 PCM 可以测下游。真机续验所需条件是该 Host 责任主体的语音识别批准、Apple 中文设备端资源，以及可按 UID 明确选择且不会拾取环境声的测试输入。条件具备后再验证同一 Recording 和 during Attempt 的 completed terminal 与非空 final、Speaking → Standby、明确手动暂停和手改保护。[Apple 进程音频采集](https://developer.apple.com/documentation/coreaudio/capturing-system-audio-with-core-audio-taps) · [Apple 离线音频处理](https://developer.apple.com/documentation/avfaudio/performing-offline-audio-processing)
