语音设置能显示下一段预计使用的模型及准备状态。就绪的 Qwen 用于下一段；模型缺失或无法启动时使用已有的系统识别路径。共享修复处理空定稿后沿用就绪的 worker，失败的片段仍有原音。独立 Saytile 和 Nearpane 使用各自的数据、模型缓存与云端授权。
