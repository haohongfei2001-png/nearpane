# Nearpane 产品完成度与下一步

截至 P4.8 Alpha，**用户可以评价本机文字区、截图托盘、屏幕上的真实窗口轮廓；尚不能把日常桌面的窗口调度交给 Nearpane。** 在随包兼容应用上，发现、授权、平铺、暂停、排除、停止和恢复已连成真实产品路径。该应用主动提供身份和编辑代际，不代表普通 macOS 应用也能提供这些证据。

口径：**可用**指已在相应设备和对象上完成真实交互；**受限实证**仅对表中对象成立；**待现场验收**表示已有产品路径但证据没有覆盖端到端；**未接入**表示只有模型、界面片段或产品决定；**系统能力未获准**表示在已验证系统组合上没有可安全开放的动作。后者不表示所有版本 macOS 都不可能实现。依据为[产品定义](../../PRODUCT_DEFINITION.md)、[ADR-010 双模式](../../decisions/ADR-010-DUAL-WORKSPACE-MODES.md)、[011 多屏](../../decisions/ADR-011-MULTI-DISPLAY-PRESENTATION.md)、[012 全屏及工作区](../../decisions/ADR-012-DESKTOP-WORK-AREA-AND-FULLSCREEN.md)、[013 稳定预留和平铺](../../decisions/ADR-013-STABLE-WORKRECT-AND-EIGHT-WINDOW-TILING.md)，实际实现逐项列在下表。

## 建议先做的事

**首选：让用户在一次写入之前，看见“这一扇窗口是否可管、为什么、停管后能恢复什么”。** P4.8 已能真正写入、回读并恢复窗口，阻碍日用的是这条链只接受随包应用提供的见证。先在设置中完成普通窗口的只读资格与恢复预演，可在没有新账号、麦克风或桌面切换授权时独立开发。即使结论是某个应用未获准，用户也得到可执行的解释。只有满足下一行的真实验收，才考虑对第一类普通窗口开放；不开启全局自动接管。

以下是优先级和验收条件，不是已启动的下一阶段。按用户任务影响排序，五个最大缺口是：普通应用逐窗纳管与恢复、设备端中文语音、单次草稿附加、Native 整行切换、原生全屏及回到原布局。Virtual 仍是正式产品承诺；在出现新的可恢复机制前冻结实机工作。

| 优先级 / 任务 | 具体缺口与目标 | 依赖与可执行范围 | 完成条件 |
| --- | --- | --- | --- |
| **P0 · 普通窗口准入、预演与可撤销授权** | 将随包进程才能提供的证据拆清；按窗口显示同意范围、可恢复基线、排除理由及撤销途径 | 先做无写入路径，沿用签名/启动代际、AX↔CG 唯一性、编辑与竞争检查。需要实写时只选另行授权、已在工作区、可正向证明的新空白普通窗；没有新见证不再重试旧 TextEdit 条件 | 授权前 0 票据；同 App 的未授权兄弟窗永不变；允许对象真实回读符合布局，暂停无写，退出能恢复；身份重建、异常几何、用户中途移动或冲突时停止且不覆盖用户，失败可解释 |
| **P0 · 中文讲话到可继续编辑的文字** | 让物理输入也能交付本次 final，而非只验证合成音频 | 复用本机已验证的领域链。仅在本人选择的安静时段、当前 Host 有正常权限时录两句专用短句；授权前可完善设备可用性提示，不重装驱动、不使用付费服务 | 声级随输入变化；逐次关联 Recording、Attempt 自己的 completed terminal 和有效 final；说完待命，手工暂停正确，第一句编辑不被第二句覆盖 |
| **P0 · 一次截图附加到指定草稿** | 联通已工作的本地托盘与普通候选中尚未开放的浏览器动作 | 需要合法、独立、已登录测试草稿，仅一张合成图。先做有绑定的受控验收；没有登录条件保留本地截图。日常入口另以明确授权和同等证据准入 | 一次输入、一个指定资产/窗口/文档/composer，START 后有原 Riftlet 认可的完成回执及浏览器证据；未发送；重启不重复。UNKNOWN 保留，不补传 |
| **P0 · Native 整行切换的首个受支持系统组合** | 让已见证的空间行拥有可验证的实际动作 | 外部准入项。仅在一次明确授权的无人使用时段，已有 A/B 两个见证和可执行返回路径时复用现成程序；不把独立登录环境建设排成新的首要开发任务 | 三轮 A→B→A，每次两屏 current、窗口 membership、焦点、代际、过渡和返回均匹配。仅开放该 build 的行切换；跨空间移窗、创建、删除须各自另证 |
| **P1 · 原生全屏及返回** | 把已有模型接入用户手动唤出的工具浮层、来源身份和返回布局 | 先用专属可控窗口和既有 WorkRect 恢复路径。真实全屏会影响系统空间时另获授权，默认不自动展开 | 当前窗口/显示器/工作区一致；进全屏不残留预留或遮挡控件，收起不抢焦点，退出按当前设置恢复；来源消失时拒绝旧动作 |
| **P1 · 日常设置、动效和设备变化** | 提升禁用原因、按模块/整屏恢复默认、双屏角色变化、动态材质及截图反馈的可理解性 | 复用现有设置页及录屏；对于真实玻璃或选区磁力，只在两层背景均可合法取证、全程不影响个人桌面的条件下验证 | 首次用户能找到收音、截图、暂停与安全停止；修改或重置一组参数不动他屏；用动态证据证实真实选区到托盘或明确保留未决。设备断连/恢复有正确边界 |
| **P1 · 发布与长时可靠性** | 个人机 ad hoc 产物还不具备公开分发或升级承诺 | 选定支持的 macOS/机型、干净测试机和签名主体后再做；改动确实影响驻留时才扩展长期测量 | 验证升级与回退不损资料；测得有场景的 CPU/内存/耗能；如要外发，签名、公证、Gatekeeper、全新设备启动及缺少权限的降级全链通过 |
| **P2 · Virtual 物理机制及其余扩展** | 保留逻辑工作区目标，当前没有可靠单窗停放机制。可选模块扩充不阻碍前述日用闭环 | Virtual 仅在有新的可维护系统机制、新隔离与兼容见证后重新评估；不做屏外坐标、同一最小化夹具或全应用 Hide 的重复实验。可选模块仅开发有明确用户任务的部分 | 同 App 不同组不相互隐藏，切回全部可访问，强退后幂等，保护用户布局；缺一项继续禁用。可选模块按权限隔离并可独立移除 |
