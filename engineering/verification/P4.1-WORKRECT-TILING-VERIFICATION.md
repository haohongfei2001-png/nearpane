## 真实观测与隔离实验

- **真实 macOS 只读。** 最终 Debug helper 在 macOS 27.0 build 26A428 回传 fresh、稳定的 1920×1080 主显示器和旋转 90° 的 800×1280 副显示器，两屏 backing scale 均为 2。窗口白名单、anchors 均为空，实验性 Space 读取关闭，窗口数和 Space 行数均为零。本次未拍摄桌面、打开可见面板、触碰主屏焦点或执行 Space 动作。P4.0 封存清单 262 项在改动前全部复核通过；历史副屏合成窗的稳定实测几何差为 0 pt。[P4.0 原始验证范围](P4.0-readonly-desktop-closeout.md)
- **真实进程退出、合成窗口。** `VirtualWorkspaceExperiment.swift` 的文件日志先于模拟窗口写入。测试子进程在第一个模拟窗口已停放、第二个尚在原位时写出边界标记并停住。父进程确认自己的子进程 PID、采样两窗，发送 SIGKILL，核对退出信号，再重新获取独占日志，校验中间状态并恢复。还验证了并发所有者拒绝、外部改动保留、目标缺失、创建/迁移/空源清理和用户退出时保留自定义布局。该夹具一次持有一笔可逆事务，缺少连续生产接管、真实第三方窗口控制和电源故障耐久性验收。
- **隐藏 AppKit 面板。** 用真实 NSPanel 在不 orderFront 的情况下验证双控制器、唯一驻留、独立宽度和隐藏/唤回。AppKit 在本机可把请求的 213.5 pt 宽量化到 214 pt。控制器分别记住请求 frame 与实际 frame，避免每个观测周期重设同一尺寸。没有新增真实截图、录音或浏览器上传收据。
- **失败证据。** 早期强退夹具未正确传递 SwiftPM 测试 bundle；随后把子进程自杀改为父进程在已见证边界终止，消除信号投递时序的不确定性。并发回归发现锁释放竞争，已把未成功加锁的描述符与所有者分开，并显式解锁。旧增量集成产物曾在托盘尺寸读取处 SIGSEGV；保留原构造入口后，该缓存中的托盘针对性测试通过。最终集成测试另外使用本轮新建的编译缓存验证。失败日志与崩溃摘要一同封存。
