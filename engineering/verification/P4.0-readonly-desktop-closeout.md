当前 Space 可有两类独立见证。自有普通窗口需在当前 Space、可见、未最小化、非全屏、未配置为驻留所有桌面，且完整位于同一显示器。父进程在收包时再查一次。普通应用窗口可使用 AppKit 当前活动 Space 可见窗口编号清单，需同时通过唯一的标准 AX↔CG 匹配、进程生命周期、单显示器几何和非全屏/非最小化检查。两个读端和交付时均核对活动清单。两类见证都要求同期稳定的单一 membership 等于该 scope 的 current。实验只接纳本轮已校准的 raw type 0。仅有 raw type、current、窗口在屏或 scope 计数均不足以生成行。多屏联动配置保持未知。整个链路不产生激活凭证。[Apple 活动空间窗口编号](https://developer.apple.com/documentation/appkit/nswindow/windownumbers%28options%3A%29) · [Apple 的窗口活动空间属性](https://developer.apple.com/documentation/appkit/nswindow/isonactivespace) · [P1 技术审查](../../docs/reviews/P1-TECHNICAL-GATE-REVIEW.md)

## P3.8 剩余现场条件

- **真实中文语音仍为 ENVIRONMENT BLOCKED。** 最终隔离 Host 使用固定 Saytile 的等价语言匹配、`progressiveTranscription` 和 Apple 官方资源准备路径，首次报告未安装，准备后另起同一 Host 的断网进程报告已安装。麦克风 TCC 为 3（authorized），旧式 `SFSpeechRecognizer` TCC 为 0（notDetermined）。系统列出的两种输入分别为蓝牙与机内设备，均无法证明不会收录环境声。本轮未开启采集，未产生新的语音采集 Recording、Attempt、terminal 或 final。下次需要可按 UID 验证且仅携带合成声音的输入。固定本地 SpeechAnalyzer 路径与旧式识别权限分开记录。只有实测所需的系统授权才需所有者响应。[Host 资源准备](../../build/verification/p40.CUdClc/host-zh-prepare.log) · [Host 离线复查](../../build/verification/p40.CUdClc/host-zh-after.log) · [已实现的固定领域调用](../../Sources/NearpaneHost/NativeAcceptance.swift) · [测试音源现状](../../build/verification/p40.CUdClc/device-transports.json) · [Apple 资源机制](https://developer.apple.com/documentation/speech/assetinventory)
- **真实 ChatGPT 附加仍为 ENVIRONMENT BLOCKED。** 标记过的专用配置仍是 0700 空目录，缺少合法登录的纯测试草稿、browser-before、一次性绑定和服务端完成证据。已保留固定 guard、单资产及 UNKNOWN 策略。只需所有者提供或登录专用测试账户并指定草稿，已有适用自动化权限后由工程侧执行。没有打开 Chrome、读取私人会话或上传附件。[本机条件](../../build/verification/p40.CUdClc/browser-conditions.json) · [既有 headless 适配器收据](P3.8-native-experience-closeout.md)
