# Nearpane 桌面能力与日常使用范围

2026-11-17，5.15 Alpha。此表按用户实际可以完成的操作维护。VERIFIED 限于所列实测环境，IMPLEMENTED 表示产品已接线且仍缺对应现场，PARTIAL 表示流程只通过了一部分。完整发布与测试收据见[单屏工程与交付](P5.15-SINGLE-DISPLAY.md)。

| 正式能力 | 状态 | 用户能做到的事及边界 |
|---|---|---|
| 观察真实显示器、普通窗口与空间记录 | VERIFIED（本机系统构建） | 在一块 1470×956 pt 显示器上，区域内两个自有窗口独立见证了当前普通桌面，两次读回一致。三条内部记录仅有一条获得当前桌面见证。 |
| 展示实际桌面及其窗口 | PARTIAL | 单屏当前行通过两个真实重叠窗口的坐标、遮挡和命中验证。同进程同形窗口有正向编号时可区分；不一致维持只读。切换离开后，仅有稳定身份的历史行可保留，后台窗口布局仍待现场。 |
| 预览经指定窗口的实际内容 | VERIFIED（逐窗入口与自建普通窗） | 在窗口管理中选一扇窗，点「拍摄此窗的桌面预览」。签封 Host 实测将实际图像显示在系统窗口上，隐藏后色块清零。仅画面存续时检查已授予的权限，到期或失效即清除。Apple 系统选窗器的真人操作仍待验。[像素及清理](P5.15-SINGLE-DISPLAY-WINDOW-PREVIEW.md) |
| 单击整行切换 Native Space | BLOCKED | 历史上副屏临时桌面 B 创建成功，往返为 0/3，曾发生焦点逸出。本次单屏上没有两个可操作且能安全归还的测试桌面。保留被动观察；下一次需可隔离的相邻 A/B、两端自有窗口及可验证的焦点回程。 |
| 拖动具体窗口跨 Space | BLOCKED | 尚无逐窗移动、兄弟窗口保持、归属回读和失败后可逆的连贯实证。待已验证 A/B 上测系统公开交互，再开放独立的缩略图手势。 |
| 创建、删除原生桌面 | NOT_IMPLEMENTED（产品写入） | 实验曾创建有回执的临时副屏桌面；没有获得创建、空空间删除及可靠返回的产品适配器。在未获能力的机器上按设置走已有工作区的分割与最小尺寸检查。 |
| Virtual 逐窗停放、切换及恢复 | BLOCKED | 屏外窗口仍部分可见。普通 Dock App 的单窗最小化对照中，兄弟窗口呈现也发生变化。当前仅模拟事务模型；重新准入需独立会话下正向单窗隐藏、兄弟窗不变与强退恢复。详见[实机技术裁决](P4.2.2-VIRTUAL-TECHNICAL-VERDICT.md)。 |
| 普通窗口逐窗管理、WorkRect 与有条件恢复 | VERIFIED（特定窗口类） | 独立标准窗口已有真正的 AX 写入与 CG 回读，代表性的最终包比较误差为 0 pt。仅接纳普通、唯一、同代际且几何一致的窗口。Stage Manager 异常、模态窗等维持只读。没有面向任意应用的兼容认证。[外部窗口实测](P5.4-REAL-AX-ACCEPTANCE.md) |
| 明确范围内自动接纳新窗 | VERIFIED（当前进程、同屏、标准应用测试窗） | 授权前的兄弟窗保持原位；之后新开的合格窗口自动平铺。暂停后的新窗口未被追补。停止后验证受管窗恢复。默认关闭。[现场验收](P5.15-SINGLE-DISPLAY-WINDOW-MANAGEMENT.md) |
| 稳定平铺、比例、槽位、八窗分流 | PARTIAL | 单屏验证 50/50、60/40、槽位互换、三窗标准模板和关闭第三窗后恢复双窗历史，已确认事务的实际误差为 0 pt。此前副屏 1–8 窗已实测。9–17 窗及第九窗能力降级仅经模型验证。 |
| 边界、暂停、退出与异常恢复 | PARTIAL | 单屏上确认受管窗侵入 160 pt 预留区或越出物理屏幕右边缘后，各自纠正一次。用户的其他调整、未授权兄弟窗保持原位；正常退出可将明确比例转换到完整区域。崩溃后缺身份或发生外部修改时持久阻塞。拖动中逐帧钳制与任意应用强制边界尚无保证。 |
| 显示器角色、独立尺寸、图标展开 | VERIFIED（所列范围） | 单屏可手动唤出本屏空间预览，图标态临时展开并恢复保存的尺寸，内部模块均关闭时仍可查看空间。设置、工作区和领域实例分离。副屏角色此前有现场记录，本轮拔插和物理旋转未验。 |
| 原生全屏、主动唤出的精简工具与返回 | VERIFIED（指定副屏应用） | 26A428 的自有窗口曾实际进出全屏、打开和关闭工具、回到原焦点。5.14 在睡眠、锁屏和拓扑变化后要求新读回。当前版本的物理睡眠与唤醒、多厂商全屏尚缺现场。[全屏回读](NATIVE-FULLSCREEN-OVERLAY-RESULT.md) |
| 普通设置、排除、资料与恢复 | PARTIAL | 同一主窗口提供两个档案、显示、主题、身份预演、排除和恢复。可核对已选布局，授权预览过期即撤回。合成资料验证升级回退。权限、过期浏览器与窗口授权不继承。 |
| 语音与截图、归档、一次附加 | PARTIAL | 保留原有文字编辑、截图收录及队列，与 P5.13 使用同一资料格式。真人话语、指定真实服务草稿完成回执依然待验。此次没有录音、上传或补传。 |
| 安装与在线更新 | PARTIAL | 统一的本地开发签名安装包可双击使用。公开线上签名 feed、Developer ID、公证和真实在线升级尚未交付。 |

下一项有意义的系统验收是有明确回程和隔离焦点的原生桌面 A/B；缺少这两个条件时，仍使用已见证的只读预览。在单屏上，更多不同标准应用的兼容性可以用独立空白测试实例逐类扩展。
