# Nearpane 桌面能力与日常使用范围

2026-11-17，5.14 Alpha。此表按用户实际可以完成的操作维护。VERIFIED 限于所列实测环境，IMPLEMENTED 表示产品已接线且仍缺对应现场，PARTIAL 表示流程只通过了一部分。完整发布与测试收据见[5.14 验收](P5.14-CORE-DESKTOP.md)。

| 正式能力 | 状态 | 用户能做到的事及边界 |
|---|---|---|
| 观察真实显示器、普通窗口与空间记录 | VERIFIED（限定 OS） | 从 CG/AX 和隔离 Reader 取得坐标、前后顺序、显示器和可用的归属。26A428 实测只有一块可用屏、一个 scope 和三条普通记录。空窗口白名单得出零条有可见窗口见证的桌面行。 |
| 展示实际桌面及其窗口 | PARTIAL | 保留窗口比例、重叠、空白和坐标。已有真实窗口见证的普通桌面在离开后可以保留只读行。仅保留经核对的桌面身份，后台布局仍未知。真实系统手动换桌面后跨行展示尚待复验。 |
| 预览经指定窗口的实际内容 | PARTIAL | 默认几何与经核对的应用图标。用户通过 macOS 单窗选择器选择后，需单独验证同一 AX 对象、进程代际、CG 编号和位置。内存快照最长一分钟。[已实测自建单窗的像素颜色、尺寸及几何](P5.14-OWNED-WINDOW-CAPTURE.md)，完整由用户选窗至侧栏显示尚待现场。 |
| 单击整行切换 Native Space | BLOCKED | 历史上副屏临时桌面 B 创建成功，往返为 0/3，曾发生焦点逸出。本次单屏上没有两个可操作且能安全归还的测试桌面。保留被动观察；下一次需可隔离的相邻 A/B、两端自有窗口及可验证的焦点回程。 |
| 拖动具体窗口跨 Space | BLOCKED | 尚无逐窗移动、兄弟窗口保持、归属回读和失败后可逆的连贯实证。待已验证 A/B 上测系统公开交互，再开放独立的缩略图手势。 |
| 创建、删除原生桌面 | NOT_IMPLEMENTED（产品写入） | 实验曾创建有回执的临时副屏桌面；没有获得创建、空空间删除及可靠返回的产品适配器。在未获能力的机器上按设置走已有工作区的分割与最小尺寸检查。 |
| Virtual 逐窗停放、切换及恢复 | BLOCKED | 屏外窗口仍部分可见。普通 Dock App 的单窗最小化对照中，兄弟窗口呈现也发生变化。当前仅模拟事务模型；重新准入需独立会话下正向单窗隐藏、兄弟窗不变与强退恢复。详见[实机技术裁决](P4.2.2-VIRTUAL-TECHNICAL-VERDICT.md)。 |
| 普通窗口逐窗管理、WorkRect 与有条件恢复 | VERIFIED（特定窗口类） | 独立标准窗口已有真正的 AX 写入与 CG 回读，代表性的最终包比较误差为 0 pt。仅接纳普通、唯一、同代际且几何一致的窗口。Stage Manager 异常、模态窗等维持只读。没有面向任意应用的兼容认证。[外部窗口实测](P5.4-REAL-AX-ACCEPTANCE.md) |
| 明确范围内自动接纳新窗 | IMPLEMENTED | 用户先授权一扇窗，再选择接纳同一个应用进程以后在此屏新开的合格窗口。授权前的兄弟窗保留。撤销、暂停或重启后的旧授权失效。已实测第二扇自建窗口只产生一次创建事件，生产观察器只取到该新窗，旧窗排除。完整自动加入、实际平铺与恢复在 5.14 上仍待现场联验。 |
| 稳定平铺、比例、槽位、八窗分流 | PARTIAL | 独立标准 App 的 1—8 窗已有副屏实证，17 笔布局、8 笔原位恢复最大误差 0 pt。9—17 窗和第九窗降级由模型验证。5.14 的普通窗口双窗交换、比例、三窗移除回溯和正常退出映射已接线。Native 新建空间仍关闭。 |
| 边界、暂停、退出与异常恢复 | PARTIAL | Docked 持久预留和 Floating 工作区、在拖动结束后受控纠正。停用或显隐含义分开。无法确认原窗、系统几何、外部编辑或权限时保留待处理记录。重启后需要新的身份见证。系统级拦截所有个人窗口拖动从未启用。 |
| 显示器角色、独立尺寸、图标展开 | VERIFIED（已有现场范围） | 唯一驻留屏装载文字与托盘，另外的屏仅有空间面板。宽高、推荐玻璃、图标态和逐屏配置已接线。拓扑变化、折叠及复用有自动回归。本轮没有实际拔插、旋转或修改显示配置。 |
| 原生全屏、主动唤出的精简工具与返回 | VERIFIED（指定副屏应用） | 26A428 的自有窗口曾实际进出全屏、打开和关闭工具、回到原焦点。5.14 在睡眠、锁屏和拓扑变化后要求新读回。当前版本的物理睡眠与唤醒、多厂商全屏尚缺现场。[全屏回读](NATIVE-FULLSCREEN-OVERLAY-RESULT.md) |
| 普通设置、排除、资料与恢复 | PARTIAL | 同一主窗口提供两个档案、显示、主题、身份预演、排除和恢复。可核对已选布局，授权预览过期即撤回。合成资料验证升级回退。权限、过期浏览器与窗口授权不继承。 |
| 语音与截图、归档、一次附加 | PARTIAL | 保留原有文字编辑、截图收录及队列，与 P5.13 使用同一资料格式。真人话语、指定真实服务草稿完成回执依然待验。此次没有录音、上传或补传。 |
| 安装与在线更新 | PARTIAL | 统一的本地开发签名安装包可双击使用。公开线上签名 feed、Developer ID、公证和真实在线升级尚未交付。 |

下一项优先验证同一正常应用进程的真实“新建第二窗 → 自动加入 → 撤销 → 恢复”，再验证已选窗口图像从系统选择器出现在侧栏。这两项均可用自建窗口完成，所需条件少于 Native Space 切换。空间动作只在具备独立目标和回程时复测。
