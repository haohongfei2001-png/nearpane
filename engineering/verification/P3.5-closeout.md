## 运行边界审计

| 边界 | 源码依据、隔离证据及限制 |
| --- | --- |
| Saytile 资料及云配置 | EmbeddedModules 只传入 Nearpane/Voice。SaytileStore 自身检查文件符号链接，适配器另拒绝被重定向的 Host 父目录。独立测试库里的标记文本保持原样。DomainInput 显式构造新的 RecognitionConfiguration，固定源码默认 cloudEnabled=false，RecognitionSessionFactory 在此分支直接选本机识别。没有读取独立应用的 UserDefaults 云配置或借用其 Keychain 授权。仅在用户触发时建立音频控制器。此结论来自源码与临时库测试，未读取真实凭据或尝试真实 TCC。 |
| Riftlet 的库及排他性 | 连接只接受原有 instance.lock、格式 4 的 production 数据库，使用独立 Riftlet 相同的 flock。另一操作系统进程实际持有临时库锁时，Host 显示占用并在打开队列前拒绝，数据库字节不变。释放后正常连接，断开后下一所有者可取得锁。启动、隐藏、恢复都不会创建或镜像生产队列。本轮没有关闭独立 Riftlet 或接触其资料库。 |
| 草稿附加 | 点击按下时固定资产及接收端，验证可见性版本和权限。上游 TransferCoordinator 对已有未确认操作只按原目标观察，重启不重放旧输入。产品脚本只走文件输入，过滤发送/提交控件。原测试覆盖重复点击、过期草稿、UNKNOWN、正回执及安全重试，传输目标为合成 transport。真实浏览器中的单次附加和未发送仍需要两侧证据，验收程序会核对指定窗口/标签、原草稿标记、用户消息身份、唯一 START 与观察时间。 |
| 隐藏、断开、退出、重启 | 普通隐藏只撤销托盘交互及飞行动效，保留显式选择的收音状态。停用语音或退出会等待草稿写入和设备关闭。已修复过期连接、已接纳输入/观察、媒体写入和目录监听收尾同新连接之间的竞态。Host 等待结束后才答复 terminateLater。已经送入外部服务的输入由原日志处理，拒绝用断开推导失败并自动重发。新会话恢复持久文字与偏好，麦克风、目录监听和外部附加许可重新建立。 |
| Spaces 与可见验收 | 普通 Host 仍保留未知归属并拒绝 Space 切换及窗口激活。可见侧栏、焦点、真实麦克风、截图选择、上传指定草稿、视觉/动效均没有在本轮运行。[后续自动检查、操作和授权范围](P3.5-native-acceptance.md) |
