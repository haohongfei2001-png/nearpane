# P4.3 Native Spaces 动作准入

**Native 空间切换继续关闭。** 本轮授权以专用、无人使用的隔离图形登录会话为前提。设备预检确认当前执行端仍处于此前保护用户主屏的登录会话，未进入动作适配器实现阶段。[实机预检收据](P4.3-NATIVE-SPACE-BEHAVIOR.md)

| 准入条件 | 判定 |
| --- | --- |
| 独立测试登录会话 | **首要阻塞**。当前执行端、控制台及历史现场比对均未识别出独立测试会话 |
| 系统动作与主屏隔离 | 未取得隔离证明。separateSpaces=true 只描述设置，两屏实际联动情况未知 |
| 可用的专用 A/B | 未核实。没有在日常会话寻找、创建或指定测试桌面 |
| 窗口与 Space 身份、回程 | 本轮无来源和目标见证，尚无可验证的 B → A 返回路径 |
| 系统切换路径 | 未测试可靠性。当前控制器已有 AX 权限，未发生系统切换调用或错误返回 |

**所需的一次性交接**是从一个与日常桌面独立、可无人值守的 macOS 图形登录会话启动本任务，并指定该会话内供试验的两个普通测试 Space。用户只需交付环境。窗口创建和登记、两屏初态记录、三轮切换与返回、恢复核验和清理由工程端负责。现有专项授权在条件满足时适用。

接手后先在该会话绑定系统 build、两屏 UUID、A/B 与各自的合成窗口、初始焦点和回程。现有单次 Reader 的 AX 元素标记仅在其进程内有效，跨 revision 的身份见证仍需在现场取得。每一程都须关联本次操作、两屏 current、目标窗可见性、唯一 membership、真实 frame、焦点和动画后两次稳定读回。身份变化、未知落点或回程失效时停止输入。[来源验证](../../Sources/NearpaneCore/NativeOriginCheck.swift) · [P4.3 停止及恢复矩阵](P4.3-NATIVE-SPACES-ENTRY-GATE.md)

本轮确认现有 Native provider 的 apply 和 rollback 均返回 unavailable，只读观察能力中的 spaceSwitching 和 windowActivation 均为 false。整行点击对应空间切换意图，拖动窗口缩略图对应独立的移窗意图。Native 切换、逐窗激活、跨空间移窗、创建和删除均未开放。Virtual 停放维持 P4.2.2 的 BLOCKED 裁决。[动作适配器](../../Sources/NearpaneCore/WorkspaceActions.swift) · [只读能力声明](../../Sources/NearpaneCore/DesktopObservation.swift)

本轮仅提交两份工程报告。交付检查覆盖差异范围、Markdown 本地链接和 Git 补丁空白。无源码、依赖或构建配置变更，本轮未触发回归测试及 Debug/Release 构建。
