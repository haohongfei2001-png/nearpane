## 真实 WorkRect 及恢复

测试调用已安装包内与「平铺体验」共用的监督入口；通过已签名的独立进程 AX 写入，逐窗回读 AX 与 CG。未操作用户已有窗口。为守住前台边界，未在用户使用主屏时用鼠标点击设置窗口。尺寸变更写入隔离 Host 配置，结束时恢复原配置。

| 场景 | 现场读回 |
| --- | --- |
| 驻留与悬浮 | 驻留时副屏普通窗获得 700 × 1280 pt；仅改隐藏状态无新 setter。变更持久配置使该屏为 Floating 后扩大到 800 × 1280 pt |
| 成员与自定义历史 | 1 → 2 → 双窗 61% 且交换槽位 → 3 → 2。三窗使用标准模板，移除第三窗后两窗 CG frame 逐一与先前自定义值相同。逐步核对无重叠、空洞、越界，最大分量误差 0 pt |
| 正常退出 | 最终退出回读与明确布局意图一致，该次退出无需再移动；测试窗关闭并由 CG 确认清理 |
| 独立焦点拒绝 | 另一轮中途前台 PID 不再匹配，夹具未成为 active、key 或 main。下一次候选布局拒绝，新增写入 0，CG 确认三扇测试窗全部消失。此轮记录为中止，不计入完整往返成功 |
| 崩溃恢复 | 冻结包另建一扇副屏窗。仅在副屏范围内写入，待 AX/CG 已改变且 WAL 仍标记 inFlight 时强退写入器。独立进程恢复同一身份与原 frame，用 1 次 setter；再次恢复 0 次。夹具正常退出、CG 确认消失。此次仅终止写入器，没有终止整台 Host，也没有进行 Virtual 停放 |
