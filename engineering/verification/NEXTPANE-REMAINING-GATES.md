# Nearpane 个人 Alpha 的三项现场交接

工程端负责启动验收、记录回执、检查结果和清理。以下三项可独立安排，均不影响本地文字、托盘或只读预览的体验。

| 项目 | 设备所有者需要做的一件事 | 工程端完成的验收 |
| --- | --- | --- |
| 一次真实中文输入 | 选一段不会录入旁人或私密谈话的时间，明确允许候选在该段时间使用内建麦克风，说一句约定的测试短句，例如「现在开始侧栏测试」。如果 macOS 在首次使用时提示，核对 Nearpane Alpha 身份后按需准许本次麦克风或语音识别。当前候选已查询到麦克风 authorized、中文资源已安装 | 使用隔离资料关联本次 Recording、during Attempt、该 Attempt 的 completed terminal 和非空 final。核对说完回待命、主动暂停和手工编辑保护。麦克风仅在约定窗口运行。缺少任一证据则保留待验 |
| 一个合法的 ChatGPT 测试草稿 | 在专用 Chrome 配置中自行登录测试账号，打开只有合成内容、已有独立会话地址的测试对话，在输入框留下下述标记且不发送，把这个测试草稿交给工程端。不需要交出密码、验证码、Cookie 或私人 profile | 核对专用进程、窗口、标签、文档、composer、无附件基线。冻结一次性绑定与本轮唯一合成截图的 SHA-256。只触发一次上传，检查原领域回执及未发送状态。UNKNOWN、目标变化或收据不足时保留原队列，不补传 |
| 一次无人使用 Mac 的时段 | 给出明确的本地起止时间及两个可用测试 Space，确认两块屏幕在此期间均可联动，并授权工程端在该时段仅用自建窗口三轮 A→B→A、恢复并清理 | 先绑定本次授权、来源与目标身份、两屏初始状态、前台及返回路径。没有正向 A/B 见证即停止。逐轮比对双采样、窗口归属及恢复。既有独立会话工具会拒绝物理控制台，工程端须按本次授权准备对应的现场入口。无需预先搭建远程桌面 |

**专用草稿入口。** 本机交付目录的「专用草稿登录.command」由设备所有者在愿意登录时双击。它先校验专用资料目录及 Chrome 签名，启动空白专用窗口；已有 Chrome 运行时会停止，可以等自然空闲时再开。打开 ChatGPT 后，目标地址须为 `https://chatgpt.com/c/…`，草稿无附件，输入框仅保留下列一行：

```text
NEARPANE-TEST-72696340-01cb-41c7-9f27-5bd26f52e31a
```

工程端已经准备零资产、零操作的会话 `72696340-01cb-41c7-9f27-5bd26f52e31a`。目标绑定由工程端在正式操作前生成，有效期 15 分钟。会话失效时由工程端生成新的匹配会话与标记。候选默认不获取浏览器控制权。只有实际专用测试主体需要且所有者同意时才接受系统提示。[专用启动器](../../scripts/acceptance/browser-profile.py) · [目标与回执](../../scripts/native-acceptance.py) · [Native 现场门槛](P4.3.1-ISOLATED-GUI-READINESS.md)
