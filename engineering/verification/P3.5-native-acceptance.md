# 下一轮原生体验验收

日常构建和本轮准备都可在隐藏环境完成。真实验收由执行代理操作专用测试应用和草稿、收集证据并复核界面。用户只需决定现场操作的授权范围，以及在系统只允许本人操作时处理对应权限弹窗。

## 已可执行的离线准备

```sh
scripts/native-acceptance.py prepare --app build/release/Nearpane.app
scripts/native-acceptance.py report --session <输出的UUID>
```

准备程序检查成品资源，在 NSApplication 创建之前返回。它在 `build/native-acceptance/<UUID>/support/` 创建新测试目录、空的生产格式 Riftlet 队列及独占锁。实际语音模块在后续启动时才会建立此处的 Nearpane/Voice 库。会话绑定创建它的可执行文件 SHA-256，拒绝重用目录或切换成品。准备程序只编译后续抓取单个窗口所需的工具。初始报告应为零次启动、零张截图、零个转移，所有现场项目待验。

## 单独授权后由代理执行的步骤

| 实际操作 | 需要的授权和数据范围 | 代理检查 |
| --- | --- | --- |
| 显示隔离版侧栏，观察常驻、点击与隐藏/恢复 | 可见 GUI、在测试窗口内点击和观察焦点。若所选工具需要辅助功能权限，事前一并列出。 | `launch` 运行绑定的成品。默认观察连续 60 分钟，可用 `report --idle-minutes N` 指定本次观察长度。比较窗口与目标显示器的实际边缘、宽高，记录面板成为 key 和应用激活通知。只计算连续心跳，睡眠或中断形成缺口。 |
| 检查实际外观和按钮/缩略图布局 | 屏幕录制或单窗口截取权限，仅限此验收进程的侧栏。 | `capture-panel` 复核运行进程的包标识、可执行文件和窗口编号，使用 ScreenCaptureKit 取得该窗口的 PNG。代理检查标题、文字流、比例、缩略图和系统材质，对照视觉权威后用 `review-visual --verdict pass\|fail` 记录图片哈希与结果。动态磁力效果需另看实际过程，静态图无法证明。 |
| 开启真实麦克风，输入短的合成测试话语并结束 | 实际录音、可能出现的本机麦克风和语音识别提示。如需播放合成音源，也纳入授权。使用已获准的测试设备和本机已安装的语音资源。 | 代理操作单按钮并观察 speaking→standby、出现文字以及托盘同一批资产的指纹。核对真实输入准确率时单独检查本次测试语句。云端 ASR/GPT-6 及付费调用不属于这组步骤。 |
| 生成一张测试截图，连接托盘，断开并重连 | 系统截图选择器、屏幕捕获及目标测试窗口操作。只选择含合成内容的测试窗口。若要测试目录监听，另列出确切测试目录和可读取范围。 | 显示三个区的实际布局。确认同一张图进入隔离队列、重连后 ID 指纹相同，语音仍可用。测试中断和恢复使用临时库，独占冲突用临时持锁进程。 |
| 点按缩略图附加到一条指定的测试草稿 | 事先明确 Chrome 测试配置、确切已有测试会话 URL、允许向该服务上传的合成图片，以及代理可写入测试草稿的权限。读取检查点和实际附加分别可能需要 Automation/Apple Events 许可。如需改变浏览器的 JavaScript from Apple Events 设置，需先列明。 | 代理在指定编辑器中填入唯一的 `NEARPANE-TEST-<UUID>`，保持未发送。先运行 `browser-before`，点按缩略图一次，出现稳定附件后运行 `browser-after`。两次相隔至少 5 秒的末态观测须匹配原页面、标签、窗口、用户消息身份、未发送草稿标记及唯一附件，同时与 SQLite 中唯一目标、尝试、START 和时间顺序一致。证据不全时不能判为通过。 |
| 正常退出再启动，核查历史操作 | 同一隔离包的可见退出和重启。 | 检查上一进程排空写入，下一进程起始收音暂停、库未连接。核对队列计数、待确认操作及现有草稿，确认没有新的输入尝试。 |

上述可见操作、权限请求和浏览器读取/输入在 P3.5 中均未执行。单个窗口图和原始验收材料保留在忽略目录。未来需要授权的调用如下，`launch` 在单独的代理进程运行，其他命令与其共享同一会话编号。浏览器检查点只读页面并保持当前标签。草稿填入和点按必须由已授权的代理在实际产品界面完成。

```sh
scripts/native-acceptance.py launch --session <UUID> --app build/release/Nearpane.app
scripts/native-acceptance.py capture-panel --session <UUID> --app build/release/Nearpane.app
scripts/native-acceptance.py review-visual --session <UUID> --verdict pass
scripts/native-acceptance.py browser-before --session <UUID> --url <指定测试会话URL>
scripts/native-acceptance.py browser-after --session <UUID> --url <同一测试会话URL>
scripts/native-acceptance.py report --session <UUID>
```

`PASS` 对应已采集的具体观察窗口。未出现说话、缺少 START、草稿或页面标识模糊，以及真实焦点或恢复数据缺失，均不足以宣告对应项目通过。浏览器 DOM 变化可能使检查点不可用，需保留不确定状态。此验收不执行 Spaces 切换或用户窗口搬移。
