# P4.7.1 普通应用兼容性裁决

**TextEdit 受限自动管理仍为 BLOCKED。** 本次解决了独立进程与指定空白文档的识别问题。决定停止的现场证据是首窗的 AX frame 完全位于主屏。CGWindowID 也未得到唯一确认。Nearpane 对该窗口零几何写入，因而没有真实平铺、焦点随写入变化、正常恢复或异常恢复的合格样本。[TextEdit 实机验收](P4.7.1-TEXTEDIT-NATIVE-ACCEPTANCE.md)

| 能力 | 裁决 |
| --- | --- |
| 独立实例、指定文件、普通 AX 窗口、清理 | 本机成功见证，同一启动代际正常退出，窗口无残留 |
| 首窗副屏隔离 | 本次未满足。请求隐藏后，取样时应用仍报告未隐藏。保持主屏原状并终止本次试验 |
| 对 TextEdit 的写入、入组及恢复 | 保持关闭。已有产品控制器限定随包签名应用，要求精确身份、最小尺寸及可验证的恢复状态。本轮没有取得支撑 TextEdit 扩展的证据 |
| 其他应用 | 仅原有、已授权的随包副屏兼容窗口在既有管理范围。普通 TextEdit、Calculator、Preview 及其他用户应用均未纳入自动管理 |

没有发现需要修改 Nearpane 产品代码的实机缺陷。恢复器和管理器没有收到针对此 TextEdit 窗口的事务。可继续验收的最小前提是能在当前授权范围内取得**初始即完全位于副屏**的独立空白窗口，之后仍需完成同代 CG/AX 身份绑定，并经产品路径验证几何和恢复。本次不据首窗结果推断 TextEdit 会接受或拒绝 AX 尺寸写入。
