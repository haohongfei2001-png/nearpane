# P4.6 窗口管理产品化

个人 Alpha 已开放一个经过现场验证的范围：当前登录会话、已授权的副屏、随包签名的兼容应用，以及该应用在活动桌面上可见的普通窗口。首次启动管理为关闭。打开兼容窗口和授权修改其布局是两次独立操作。成品源码为 `0a4dc9397bface07790bc49d7e03e20cb514a0a7`，基线为 `eccdd339fb2ad8f1c08222c5c072aeb14536ddde`。

## 产品入口

Host 启动时连接管理服务，Settings 的「窗口管理」负责首次说明和授权、暂停、继续、停止并恢复，以及错误后的重新核对。每个已发现窗口可单独排除，双窗可以保存比例、交换槽位、确认窗口上的手动调整。「窗口规则」保存应用排除、新窗口归属及八窗分流策略。「尺寸与呈现」保存每屏的驻留方式和预留宽度。主驻留屏持续预留，其他屏的 Floating 使用完整可用区。[Host 生命周期](../../Sources/NearpaneHost/NearpaneApp.swift) · [窗口管理设置](../../Sources/NearpaneUI/CandidateWorkRect.swift) · [每屏尺寸](../../Sources/NearpaneUI/WorkspaceDisplaySettings.swift)

## 窗口从发现到写入

- 兼容应用提供实例登记、窗口代际、最小尺寸、可见性和编辑状态。管理服务以两次稳定采样合并事件。实际 AppKit 窗口增减会触发布局，服务无需收到创建窗口的命令。主界面显隐和模块呈现未进入几何变更条件。当前实现使用合作应用登记和轮询，尚无任意应用通用的窗口发现及写入许可。[兼容应用](../../engineering/window-lab/Sources/NearpaneFixtureWindows/main.swift) · [管理服务](../../scripts/window-management.py)
- 控制器验证存活进程的路径、签名、进程启动代际、唯一 AX 元素、CGWindowID、角色、可见状态及显示器。写入前重新检查资料、Host、写入进程、授权、排除、实际 frame 和工作区配置。每个位置或尺寸操作均有 AX/CG 回读。Host 与控制器各自持有排他租约。观察到未获确认的外部调整时停止自动写入，Settings 可确认合格的手调双窗。外部 AX 写入器之间没有系统级原子锁。[身份及显示器](../../engineering/window-lab/Sources/WindowLab/Scope.swift) · [写入前核对](../../engineering/window-lab/Sources/NearpaneFrameController/FixtureAdapter.swift) · [授权和焦点](../../engineering/window-lab/Sources/NearpaneFrameController/ProductManagement.swift)
- 使用原有 WorkRect 和渐进分割算法。当前可见窗口组有独立登记，没有获证的系统 Space ID。新窗独立归属和超八窗优先新建分别参与判断。创建能力关闭时，控制器在回执中记录降级并尝试当前工作区分割。每窗最小尺寸仍须满足。控件不会触发创建、切换或删除 Space，也不会停放窗口。[准入](../../Sources/NearpaneCore/WorkspaceAdmission.swift) · [布局与历史](../../Sources/NearpaneCore/ManagedWindowTiler.swift)

## 暂停、退出和异常

| 事件 | 产品行为 |
| --- | --- |
| 隐藏侧栏 | 管理继续，Docked 预留持续生效 |
| 暂停 | 停止新的自动平铺，窗口保留在当前布局，历史和恢复记录保留 |
| 停止并恢复 | 先完成可验证恢复，再关闭授权 |
| 明确退出 | 撤销自动改变，用户保存的双窗分割映射到完整可用区。正常退出保留已有管理设置 |
| 强退并重新启动 | 独立兼容应用可跨 Host 继续存活。重新验证授权和当前窗口，先处理日志中的在途动作，再开始新的调度 |
| 身份、写权限或外部调整冲突 | 显示实际失败原因，冻结有歧义的写入。恢复器保留未解决记录，按可验证身份处理可恢复对象 |

日志在每个 AX 原语前同步文件和目录。崩溃恢复使用本次事务开始时的 frame，正常退出另行采用首次纳管位置或明确保存的布局。两者均需当前实际身份与读回。[事务与恢复](../../engineering/window-lab/Sources/NearpaneFrameController/FrameJournal.swift) · [现场回执](P4.6-NATIVE-ACCEPTANCE.md)
