## 安装与使用

在 Finder 打开 [Nearpane P5.0 Alpha.app](</Users/hhf/Applications/Nearpane P5.0/Nearpane P5.0 Alpha.app>)。这是独立的本地开发签名包，Bundle ID 为 `com.holdsnow.nearpane.candidate.p50`。首次正常启动使用空的 `~/Library/Application Support/Nearpane Alpha P5.0`。P4.9 安装及其独立资料可继续使用。验收用的 PNG 只进入本轮临时库。

1. 打开 **Settings → Riftlet**。需要收纳 macOS 快捷键截图时，点「选择当前系统截图目录并收录…」，选系统当前实际保存截图的目录。变更目录后需重新选择。
2. 点「允许附加到当前浏览器草稿…」。这个授权可关闭。保持要使用的 Chrome ChatGPT 草稿在前台，点击托盘的一张截图。此后的正常点击无需文件选择器、测试标记或测试会话。
3. 从托盘或同一设置页查看状态。看到「已开始上传，尚无完成回执」或「结果未知」时，核对原草稿。重启和恢复不会再次提交那张图。
