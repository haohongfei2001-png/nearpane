# P4.4 个人 Alpha 候选

2026-11-10，macOS 27.0（26A428）。**可以开始个人 Alpha 体验。** 本次可评价文字工作区、图片托盘、当前桌面只读预览和副屏测试窗平铺。真实语音设备、浏览器附件和系统空间调度各有独立的准入条件。

## 在这台 Mac 打开

在 Finder 按 ⇧⌘G，输入 `~/Applications/Nearpane P4.4`，双击 **Nearpane Alpha.app**。首次打开会在接入的首块外屏显示完整侧栏；只有一块屏时使用该屏。退出再开保留指定的驻留屏。菜单栏的侧栏图标提供 **Show / Hide Surface**、**Settings…** 和 **Quit Nearpane**。在设置的「显示器」页选驻留屏，在「尺寸与呈现」页调整该屏的布局。在「平铺体验」可建立本次专属普通窗，体验后选择「结束并恢复」。

首次有一条示例手记和五张合成图。滚动托盘可见末图和截图入口。文字可选择、编辑、复制。资料写在 `~/Library/Application Support/Nearpane Alpha`；首次以临时目录完整初始化后原子发布。资料标记不匹配时停止打开。Voice、Riftlet 的数据库与锁由候选单独持有。主动断开 Riftlet 的选择会保存。双击入口使用常规资料；工程验收用了单独的有标记会话和副屏参数。

## 产品动作及开放范围

| 能力 | 本版实际行为 | 证据范围 |
| --- | --- | --- |
| 文字与托盘 | 单一 Host、单一 Voice/Tray；可编辑、复制、滚动、展开、收起、主动截图、正常退出和恢复队列 | 本轮实拍托盘、复制动作、收录和重启。文字编辑及焦点归还沿用先前真实验收 |
| 驻留屏与其他屏 | 完整面板仅在驻留屏；其余屏按需、自动或固定显示 Space-only。支持停靠、悬浮、精简及显式隐藏。设置保存每屏尺寸和隐藏意图 | 本轮看到副屏驻留实例。双实体屏同时呈现由既有编排及回归覆盖，本轮未在使用中的主屏打开第二个可见面板 |
| WorkRect | Docked 隐藏后仍预留；Floating 无预留。只有候选自己创建且登记的普通窗可写入。设置页可增减 1–5 扇，调整双窗比例与槽位 | 最终包实测 1–3 扇及崩溃边界。P4.2 的独立现场覆盖 1–5 扇；用户日常窗口无自动接管入口 |
| 桌面预览 | 默认显示新鲜、已观察的窗口几何。Space 归属实验须单独启用，缺证据时提示未知。有证据时才画相应空间 | 副屏一行区域内两扇登记窗获 AX/CG 见证。系统切换能力关闭时不安装空间点击或窗口拖放动作层 |
| Saytile 识别 | 本机中文资源已就绪。候选仅在用户操作语音按钮后尝试启动采集 | 合成 PCM 经领域识别得到本次 final。设备端到端、讲话后按钮回待命待验 |
| Riftlet 草稿附加 | 普通候选关闭外部输入。仅有合法一次性绑定的专用验收启动可进入资产与目标守卫 | 真实草稿缺少登录及绑定，外部输入为零 |
| Native / Virtual | Native 当前只读。切换、创建、删除、跨 Space 移窗及 Virtual 停放均关闭 | P4.2.2–P4.3.1 结论沿用，未执行上述动作 |

主面板不加标题、Logo 或工具栏。设置独立在菜单栏中。用户选择的尺寸由显示器可用范围约束；设置页呈现生效值。八窗分流与新窗口默认归属保留为独立策略。五窗是候选自建体验的上限；日常应用及第九窗不会因此获得系统操作能力。
