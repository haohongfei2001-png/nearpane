# P4.5 个人 Alpha 核心工作流

2026-11-10，macOS 27.0（26A428）。**本地个人 Alpha 可体验。** 同一次副屏运行已见证文字复制、截图入队、当前空间预览与测试窗平铺。真人语音与 ChatGPT 附件依设备所有者本轮选择跳过，两项均无端到端 PASS。

**打开与回退。** 双击 `~/Applications/Nearpane P4.5/Nearpane Alpha.app`。首次启动使用空白文字区和空托盘，侧栏的播放按钮开始收音，相机按钮展开截图方式。菜单栏侧栏图标的「设置…」可以检查语音、选择主驻留显示器、调整尺寸或体验专属窗口平铺。新版本拥有独立的应用标识 `com.holdsnow.nearpane.candidate.p45` 和资料目录 `~/Library/Application Support/Nearpane Alpha P4.5`。示例手记及五张示例图仅由明确指定的演示会话生成。回退时退出 P4.5，打开同级 P4.4 目录中的原 App；没有迁移资料。P4.4 原交付清单与深度签名复核通过。

| 核心工作流 | 本轮判定 | 真实执行与边界 |
| --- | --- | --- |
| 首次打开、按钮与设置 | PASS，副屏 | 空资料打开及退出均为零录音、零截图。P4.4 暂停图形的 AX 点击框为 9.92 × 11.66 pt，P4.5 为 32 × 26 pt，图形本身尺寸保持原设定。中文设置增加了本机资源状态与按需准备入口。未在使用中的主屏激活设置窗口 |
| 每屏独立尺寸 | PASS，配置与副屏回读 | 给主、副屏分别保存 151、120 pt 面板宽度和不同按钮尺寸。副屏实际单窗口图为 240 × 2560 px，按钮 AX 为 38 × 30 pt。两份配置均按显示器重新读回，测试后还原。主屏没有可见试验 |
| 合成中文进入本机识别 | PASS，PIPELINE TEST | 两句已知短句经固定 Saytile AudioRing、CaptureWorker、VAD 和 Apple 本机识别。两条 final 均与预期短句吻合（忽略标点），分别核对本次 Recording、Attempt、Fusion 和 completed terminal。两次领域声级均测到四种量化值及有声后安静，未打开物理输入 |
| 编辑、下一句与界面复制 | PASS，领域编辑与原生复制 | 在验收库调用原领域编辑操作保存第一句，再识别第二句。第一句仍选择 userEdit，第二句有独立 final。打开同一资料的实际面板，点复制后从专用命名剪贴板读回 108 字节，摘要与三条可见记录一致。未对用户键盘输入或通用剪贴板取证 |
| 真人语音端到端 | BLOCKED，本轮不做 | 新包读回麦克风 authorized；系统默认仅发现单声道内建输入。最初新身份查询中文资源未安装，用已有本机资源准备后确认 installed。旧 SFSpeechRecognizer 为 notDetermined。实际设备采集、麦克风驱动的竖条、说完回待命以及继续下一句话仍待真人验收 |
| 截图与托盘 | PASS，真实单窗截图 | 五张合成图与语音记录共存。滚动、展开、系统截图、收起经过实际控件。系统截图子进程只拍本轮自建副屏窗口；第六张来源为 applicationScreenshot。外部输入 0、START 0、领域上传操作 0。未进行跨屏区域选择 |
| 空间预览与 WorkRect | PASS，只读预览与专属窗口写入 | 六个已确认样本显示一行有见证的当前空间，两扇观察窗与 AX/CG 基准均为 0 pt 误差。同时用包内「平铺体验」监督入口对另外一至两扇已登记副屏窗平铺，最大分量误差 0 pt，期间 Host 面板可见且文字、托盘在线。退出后 CG 确认两窗消失。本轮没有接管日常窗口 |
| 排空、重启与焦点 | PASS，数据及 Host 状态 | 两个不同 Host 进程均正常排空退出。重启后六张图片顺序、媒体校验、文字与队列状态一致，外部输入与 START 均为 0。交互运行中前台 PID 稳定。重启运行中前台 PID 曾变化，Host 始终未变 active/key；此次不能证明全系统前台不变 |
| ChatGPT 单次附加 | BLOCKED，本轮不做 | 既有专用 Chrome 配置的 user-data 目录仍空，没有已登录且指定的草稿。仅检查该目录，未启动浏览器。没有 browser-before/after、START 或最终附件回执。一次性绑定、UNKNOWN 保留及不自动发送策略继续生效 |
| Native Spaces 与 Virtual | BLOCKED，能力关闭 | 只读预览可用。Native 切换、跨空间移窗、Virtual 停放均关闭。本轮未重试停放或登录会话实验。P4.2 的 1–5 窗实测、布局恢复及 P4.4 的 SIGKILL 恢复收据保留 |

本轮修改集中在[候选资料初始化](../../Sources/NearpaneHost/CandidateProfile.swift)、[语音显示与点击范围](../../Sources/NearpaneVoice/VoiceSurface.swift)、[语音设置](../../Sources/NearpaneVoice/VoiceInputSettings.swift)、[模块设置](../../Sources/NearpaneUI/SettingsView.swift)和[候选打包](../../scripts/build-candidate.sh)。可见试验从真实已安装成品的受控副屏入口启动，传感器检查与 PCM 识别均未使用生产数据或收费服务。
