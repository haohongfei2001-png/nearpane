# Nearpane — independent Stage Manager replacement

The single current product and architecture authority is [NEARPANE-INDEPENDENT-STAGE-DECISION.md](NEARPANE-INDEPENDENT-STAGE-DECISION.md).

Nearpane owns the R4 flat thumbnail interface and dispatches real windows with its independent hidden-Space engine. Apple Stage Manager must be off during independent dispatch. Apple-strip mirroring, Corner parking, wallpaper shields, and pointer interception to simulate hiding are not production routes or fallbacks.

The previous text is preserved as [historical evidence](archive/pre-independent-20261126/NEARPANE-STAGE-MANAGER-CODEX-INTEGRATION-PLAN.md). It must not guide new implementation.
