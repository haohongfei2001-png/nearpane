### 前景像素检查的精度

材质图中每组窗口内部比较 52,052 个像素。其余三列相对第一列均只有 6 个像素发生变化，最大差为一个 8-bit 通道单位，即约 0.012% 的像素有 1/255 差异。检查容差为最大通道差不超过 1，且变化像素少于 0.1%；这是对分数坐标栅格舍入的容差，不允许整体前景透明度变化。正文实色笔画像素数量严格相等。完整数字见 `validation-results.json`。

## 复现

在本目录运行：

```bash
python3 render_reference.py
node render_svg.cjs
python3 build_design_book.py
python3 validate_reference.py --pdf
```

最后一步已通过 7 组程序检查，输出 `validation-results.json`。程序检查覆盖结构、尺寸、几何、状态及有限像素区域；外观判断来自上述人工图稿与 PDF 检查，不能由 PASS 数量替代。
