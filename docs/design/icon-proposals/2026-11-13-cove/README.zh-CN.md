## 4. 创意探索与淘汰

至少考察了以下八类实质不同的构造。后续的颜色、角度和圆角变化没有被重复计算为新概念。

| 构造原理 | 有价值的部分 | 根本问题与处理 |
|---|---|---|
| 偏心负空间挖空 | 完整体量、小尺寸稳定 | 很快变成C、月牙或普通环，淘汰 |
| 连续宽带回折 | 有行动感、路径连贯 | 变成b、7或普通连结符号，淘汰 |
| 不等质量双体 | 亲近、主从关系清晰 | 保留B；植物和引号联想仍在 |
| 平直悬臂与支点 | 稳定、准确 | 过于像F、Z、游标、箭头，淘汰 |
| 双曲面扫掠 | 轻盈、流动 | 太接近扇叶、RSS或通用弧形品牌，淘汰 |
| 实体加角形切口 | 紧凑、稳定 | 普通旋钮、播放或字母读法，淘汰 |
| 重复节奏 | 很容易缩放 | 音量条、声波等现成符号，淘汰 |
| 完整实体内的开放弯曲切隙 | 轮廓与负空间形成一个记忆点 | 发展为A，首选 |

还验证了共同方形包络中的双体切分。虽然两形关系比自由摆放更强，但产生了卡片、折页或咖啡豆联想，未进入最终。C来自另一种厚曲面开口结构；最终圆化大端，消除了早期斜楔过强的播放方向联想。方向调整属于该概念的精修，不算新增概念。

AI图像生成仅用于一轮单色构想。最终A经过手工重建、光学修正与真实矢量导出，B与C直接由路径构造。生成图不作为任一正式资产的底图或几何权威。未筛选草图没有混入最终展示册。

## 5. 三款候选的真实评价

### A / Cove「回湾」 - 本轮推荐

单一完整实体中形成一条由开放端收束进入主体的弯曲切隙。外轮廓安定，内部曲线带来方向和呼吸感。记忆不依赖字母、窗口或附加装饰。

精修调整了右侧质量、底部轮廓和两端，避免上重下轻或锐利运动标志的倾向。16px另作切隙拓宽稿，32px有较轻的光学校正。默认应用图标只增加同色系微弱渐变与安静的浅底，没有光晕、玻璃板或外部戏剧性阴影。

**优势：** 三款中轮廓与负空间最容易作为一个整体被记住；形状不依赖材质；既有静态质量，也保留行动感。

**边界：** 仍可能被读成鸟首、山路、帆或户外品牌；不能证明它只会使人想到Nearpane。16px保存的是基本切隙与轮廓，最尖端及精细曲率会简化。它值得优先审定，不等于已经获得用户认可或已被证明具有全球唯一性。

### B / Poise「相依」 - 安静、有机的备选

两块曲面约3.9:1，具备明确主从关系。保持分离的留白、柔和端部和偏心重心。它与A的一体切隙结构不同，是离散的双体关系。

**优势：** 亲和、安静，缩小后仍保留两个主体；不依赖文字与色彩叙事。

**根本问题：** 植物、种子和引号联想较强；两块之间的形式必然性仍不如A，16px的伴体容易退化成一片叶。即使补上更漂亮材质，也不会自动成为更有身份的Nearpane图形。

### C / Enfold「回合」 - 厚曲面与开口回转

由有力外弧、圆端开口和向内回转的轮廓组成，整体更紧凑。最终修改了早期过直的斜边和方向楔形；完整图形不再以播放按钮作为第一读法。

**优势：** 小尺寸最稳定，力量感明确，纯色形状简单完整。

**根本问题：** 可能读成种子、手势或柔软包合体；更钝，精致与灵动的平衡不如A。语义通用，缺少A的特定弯曲切隙记忆。

### 八项独立评审摘要

| 维度 | A 回湾 | B 相依 | C 回合 |
|---|---|---|---|
| 品牌独特性 | 相对最强；仍有户外/鸟首联想 | 自然双体较常见 | 抽象包合形较通用 |
| 图形美感与精致度 | 曲率、重心、切隙形成整体 | 柔和，但关系不够必然 | 稳健，较钝 |
| 产品气质匹配 | 安静且可行动，最贴合 | 亲近，但偏植物/健康 | 可靠有力，但个性偏弱 |
| 记忆与识别 | 单一负空间记忆明确 | 容易记成种子+叶片 | 开口体稳定，但泛化 |
| 小尺寸可用性 | 32px好；16px切隙可辨、尖端简化 | 16px双体分开，伴体细节弱 | 16px最稳定，槽口保留 |
| macOS环境适配 | 静态模拟匹配 | 静态模拟匹配 | 静态模拟匹配 |
| 长期使用价值 | 不依赖光效、材质时尚 | 造型耐看，品牌占有较弱 | 简洁耐看，但辨识个性弱 |
| 对官网现版的提升 | 独立轮廓、流动感与完整色块提升 | 更有机，但身份优势有限 | 体量增强，品牌优势有限 |

独立复核排序为 **A > C > B**。现版n的名称直读优势仍然存在；A不是全维度获胜。不能把B/C包装为同样已经满足最高标准的终版。完整独立评审见 `verification/final-independent-review.md`。

## 6. 品牌色提案与可检验理由

先确认单色结构，再在同一A轮廓上比较原官网橙、朱橙、青绿和墨黑。推荐保留暖色谱系，改为更完整、偏红的朱橙主体。新的主色是提案，并未追认旧色或任何历史钴蓝提案为已批准权威。

| 用途 | 色值 | sRGB颜色说明 |
|---|---|---|
| 品牌主色 | #EB5D3B | RGB 235 / 93 / 59 |
| 浅底小尺寸 | #DD4C2E | 16/32px适当加深 |
| 深色图标前景 | #FF7955 | 提高深底可见性 |
| 墨黑 | #16191E | 纯色标志、深色文字 |
| 浅色底 | #F7F8FA | 接近白色，略带冷灰 |
| 深色底 | #24272D | 中性深灰 |
| 克制的同色渐变 | #F66B47 → #E65334 | 只用于默认静态图标的大尺寸表现 |

按sRGB相对亮度计算，在同一#F7F8FA底色上，原favicon橙#F97955的色块对比约2.50:1，朱橙#EB5D3B约3.21:1，小尺寸#DD4C2E约3.84:1。深色前景#FF7955与#24272D约5.79:1。这些是色值对比计算，不代表整套图标已通过某种无障碍认证，也不等于用户识别率。

朱橙的优势在于保留暖色连续性、提高浅底对比，并把识别色从不足一像素的细线扩展成主体。青绿虽然安静，却会进一步强化这批图形的自然、植物或隐私工具联想。墨黑适合单色品牌应用，但作为默认Dock图标更匿名。没有理由为了新鲜而换成蓝紫科技配色。

## 7. 文件与使用边界

每个候选目录都包含：

- `source/`：原始标志、纯黑、反白、浅深色应用图标、16/32px光学校正版、未裁圆角的方形版本。
- `png/`：应用图标16/32/64/128/256/512/1024/2048px；透明纯色标志1024/4096px；纯黑与反白；透明角保留。
- `macos/Nearpane-light.iconset` 和 `Nearpane-dark.iconset`：16/32/128/256/512pt各1×/2×，共十个槽位。
- `macos/Nearpane-light.icns` 和 `Nearpane-dark.icns`：真正ICNS容器，已检查文件头、区块和各尺寸图像解码。
- `macos/AppIcon.appiconset`：默认浅色静态macOS图标资产目录及合法Contents.json。
- `icon-composer/01-symbol.svg` 与 `layer-spec.json`：无阴影、无模糊、无预裁外框的前景，方便进入Icon Composer。

完整规格：1024单位主画布；静态底板范围(100,100)至(924,924)；主体最大外接边约610；A主稿光学偏移(-12,+2)。同一图形不要水平拉伸、旋转替代、随意加线或更改主从比例。独立品牌标志周围建议至少保留其主体高度20%的留白；图标容器使用交付构图。

16pt@2×和32pt@1×虽然都是32物理像素，但来自不同的光学意图，因此提供两个文件，而非把其中一个复制到另一槽位。

深色ICNS是备用静态资产，不能仅靠文件名实现系统自动切换。分层`.icon`、系统Liquid Glass、dark/mono/tinted行为需要在Icon Composer/Xcode中确认。本轮没有把准备好的SVG层冒充编译完成的`.icon`。

## 9. 可再生成的源文件

`build_assets.py`读取相邻`design-config.json`，用Inkscape渲染SVG，再通过标准ICNS区块写入完整图标容器。依赖Python、Pillow、svgpathtools和Inkscape CLI。运行后输出到当前目录下的`delivery/Nearpane-Icon-Design-20261113/`。图形仍然可直接用Figma、Illustrator或Inkscape编辑，不必通过脚本才能使用。

示例：`python build_assets.py`。格式复核：`python verification/verify_assets.py <交付目录> --output validation.json`。
