# Nearpane 三款图标：最终独立视觉评审

评审日期：2026-11-13。

对象：`delivery/Nearpane-Icon-Design-20261113/` 中 A_Cove、B_Poise、C_Enfold 的实际导出文件。检查了三张 Presentation、Direct-Comparison、Native-Size-Light-Dark、Dock-Comparison-64px，以及三款纯色 SVG 源文件与 16/32 px 图标文件。C 后续圆化大端与斜切起点，本次增量另核对 `C-rounded-terminal.png/.svg`、更新后的交付 SVG，以及重新导出的浅深色 16/32 px 图标。

## 结论

**本轮排序为 A ＞ C ＞ B。推荐 A「回湾」作为本轮首选候选。** A 的连续实体与弯曲负空间形成了最清楚的记忆点；它在纯黑、反白、默认和深色图标中都能保持身份，也在统一 Dock 模拟中具备足够存在感。

这是相对当前三个候选的推荐，不能据此声称 A 已获“世界级”或永久品牌定稿认证。**目前不能把 B、C 同时描述成已经达到用户要求的三款优秀最终方案。** 它们是经过真实制作和筛选的备选，但根本的品牌识别问题仍未解决。A 也仍有鸟首、山路、帆及户外品牌联想，无法证明它只能属于 Nearpane。

## 八项定性比较

| 维度 | A 回湾 | B 相依 | C 回合 |
|---|---|---|---|
| 1. 品牌独特性 | 三者中较强。连续弯曲切隙与不对称外形有具体记忆点；仍处于道路/山帆/鸟首的视觉家族。 | 中等。两块关系可辨，但种子/叶片的常见联想较强，大小关系本身不足以形成专有身份。 | 中等偏弱。轮廓紧凑；圆化大端后播放/箭头联想明显减轻，但仍属于常见圆润开口体，独特性未因此显著提高。 |
| 2. 美感与精致度 | 本轮最好。右侧块面和下端修正有效，曲线较流畅；外轮廓的实与内部的空有张力。 | 曲线干净，但主块折口与小块关系仍显不够必然；像设计了两个形状后组合。 | 形体完整、干净，大端外弧与右下厚曲面的衔接更自然；圆化后更亲和，也更柔钝。 |
| 3. 产品气质匹配 | 动而不乱、完整且轻盈，较符合原生桌面交互产品。不能靠名称解释为必然符合。 | 亲和、平静胜过先进感，偏自然或生活方式品牌。 | 稳定可靠，力量感充分；灵动与轻盈不足。 |
| 4. 记忆与识别 | 可以记成“向内回转的白色弯道”。不靠橙色也能复述。 | 可以记成“一大一小两瓣”，但这一描述区分力有限。 | 可以记成“圆体上有一条斜槽”，容易记，但和通用抽象标志接近。 |
| 5. 小尺寸可用性 | 32 px 清楚；16 px 仍保留切隙，但尖端和曲率细节消失，属于可用的简化而非无损缩小。 | 32 px 两块清晰；16 px 小块只剩少量像素，主块折口弱化，容易读成一个果实加叶片。 | 三款中实体最稳；16 px 切槽仍在，但圆端简化为像素缺口，个性减少。 |
| 6. macOS 环境适配 | 静态浅深 Dock 模拟均自然，主体比例与邻居相称；深色版清楚。 | 静态适配成立，但视觉重心偏左下，右上小块容易被读成附件。 | 静态适配成立，体量略厚重；旋转及圆化后更像安静的包合体，方向符号感减弱。 |
| 7. 长期使用价值 | 不依赖玻璃、光晕或复杂渐变，有持续使用潜力。其价值要由后续一致应用建立。 | 不依赖特效，但泛自然意象会限制独特性；继续使用不会自动解决形状关系。 | 轮廓简单、易维护，但可能长期保持“通用抽象符号”的问题。 |
| 8. 相对官网现版提升 | 在独立图形审美、流动感与符号完整性上提升明确；字母直读和既有连续性方面没有超过原版。 | 造型更柔和，但无法确认整体品牌收益超过清楚的 n＋橙线。 | 体量与小尺寸更稳，但独特性和产品气质的提升不充分。 |

## 16/32 px：具体观察

本评审既看原文件，也看最近邻放大，而不把大图的曲率质量直接外推到小尺寸。三款 16 px 图标中明显橙色主体的外接范围约为 10×10 px；这不是文件尺寸错误，而是应用外壳与内留白共同作用的结果。

- **A：** 独立拓宽切隙的 16 px 稿有用。白色/深色切隙没有完全闭合，仍能认出原形。尖端无法保持大图的锋利回转，近似一个较直的斜弯口。32 px 保留的轮廓已足以日常辨识，深色背景没有明显混浊。
- **B：** 两个实体在 16 px 仍能分开，但右上小块和主块上部细凹口的表达不足。其风险主要是辨识内容退化，而非图像发糊；单纯锐化无助于解决。
- **C：** 重新导出的圆化稿在浅深色 16/32 px 中均保留了槽口，未出现闭塞。小尺寸实体扎实；16 px 槽底圆弧细节仍会消失，整体像有一处剪口的圆实体。32 px 新的大端圆弧可辨，播放方向感比旧稿弱，但通用图形感仍在。
- **现版：** n 依然极易识读，橙线在小尺寸相对薄弱；不能为了推荐新方案而抹掉现版这一直接优势。

三者的 16 px 都有正常的抗锯齿阶梯；最近邻放大出现方块不是导出模糊。此处不应承诺 16 px 和 1024 px 具有同样的细节。

## 禁区与源文件检查

已直接读取三款 `source/mark-black.svg`：A、C 各一个可编辑 path；B 为两个可编辑 path。纯色核心不含嵌入位图、文字图形、窗口、卡片、侧栏、门框、n 或蝴蝶结。没有依靠玻璃和橙色边缘光掩盖核心形状。

**C 的禁区增量结论：** 大端及外部斜切起点圆化后，原先容易读作方向楔形的外轮廓变成了饱满弧面，播放/箭头联想明显减轻。完整图形现在更接近带斜槽的包合体，**不再建议因播放按钮禁区直接否决**。这是同一开口回转方案的几何修正，不算新增独立概念。其剩余问题是通用、偏柔钝及个性不足，不是已确认复制播放符号。A 的动物/山帆联想和 B 的叶片联想也是品牌适配风险，不是已列禁止元素的直接复用。

不对三款进行“全球无类似标志”或商标可注册性承诺。本次没有做完备的品牌或商标排查。

## 对推荐与交付措辞的建议

可以说：**“我推荐 A。这是当前三款中形状记忆、流动感、单色成立程度和应用落地最均衡的一款；B、C 保留各自问题供比较。”**

不应说：三款都已达到顶级；A 完美；A 只有 Nearpane 能用；所有环境已验收；ICNS 验证通过等于 macOS 真机验证。

当前素材足以让用户判断和继续接入工程，但**设计判断上的置信度应停留在“明确首选候选”，不能为了任务完成而提升为“毫无保留的品牌终版”。** Dock 等图明确标为静态模拟是正确的。真机系统呈现、不同 macOS appearance 以及用户是否认可这种形体身份，尚不在本评审的已验证范围内。
