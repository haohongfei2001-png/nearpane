# 04 · 功能设计与关键状态

全部新增功能的原生状态为 **Designed**。原型中可执行的操作属于 Web prototype，不意味着系统接入已经实现。技术路线与官方证据详见 [platform-feasibility.md](platform-feasibility.md)。

## A. 统一编辑与独立笔记

工作页共享标题/日期位置、文本编辑器、选区工具、档案入口、自动保存提示、展开/收起方式。数据空间分别为便笺、计算、待办、语言；切换空间先 flush 当前草稿，再恢复目标空间上次打开的记录/选区/滚动位置。不得把同一文本框内容直接解释成另一种类型。

便笺首期支持纯文本、段落、清单、链接和文件引用；不做完整排版应用。标题可空，档案用第一行生成显示标题，不改正文。创建从空白编辑开始，不弹命名对话框；打第一字才生成持久记录，空草稿可自动丢弃。长文在已有主窗口继续编辑。

内容选择后提供“复制”“存为…”等少量明确动作，复杂结构到主窗口。扩展结构化内容必须有独立schema和渲染器，不能在统一buffer里插入任意未定义JSON。苹果备忘录互通与跨设备同步不属于本轮已验证承诺；可导出文本/文件，不制造隐形双向同步。

| 状态 | 主界面 | 动作与保存 |
|---|---|---|
| 空 | 一句占位提示 | 输入开始即自动保存 |
| 编辑中 | 正文与最少控件 | 不打断光标/IME；后台journal |
| 已保存 | 默认不长期堆成功标记 | 打开档案、复制、另存 |
| 保存失败 | 一句“尚未保存” | 重试/导出当前稿，切页仍保留 |
| 关闭/崩溃重开 | 恢复最后可确认版本与未提交journal | 不伪报已同步到云端 |

## B. 计算草稿

### 非破坏式求值

用户输入 `1280 / 8`，按键盘 `=` 或点击紧凑等号动作后，原式留在编辑器，下面暂时出现 `160` 结果。结果来自独立装饰/投影，绝不替换表达式。点结果的关闭按钮立即回到原式；再次按等号可重新计算。取消结果不清空草稿，也不静默写入答案。

首期将“表达式求值”和“文字等式”区分：在可求值的计算行，键盘等号作为求值手势；在含未知符号或用户选择“按文字保留”的行，`=` 是普通文本，`E = mc²` 不弹错误、不被改写。提供“保留为等式”动作将已确认结果显式写为文字 `1280 / 8 = 160`；此操作可撤销。不得自动修改普通便笺中的公式。

连续计算：结果可见时输入运算符或点“继续”，在新行使用此次结果的规范数值起算，上一行和历史不变。点普通数字开始新式。`Ans` 若首期提供，必须绑定具体Evaluation ID，不能借一个全产品全局lastResult把别的草稿的结果串进来。

### 首期计算范围

本地确定性解析器支持十进制、有符号数、括号、`+ − × ÷`（兼容`* /`）、整数次幂、明确的一元百分比。十进制使用Decimal或同级精度策略；`0.1+0.2`显示`0.3`。`10%`严格等于`0.1`，因此`100+10%`为`100.1`；不采用传统金融计算器的隐含加成语义。百分比帮助中给一个例子。

表达式长度、嵌套层数、幂与结果位数有明确限额，错误原地显示；不使用`eval`、shell、执行代码或LLM生成数值作为算术结果。首期无实时汇率、自然语言日期计算、单位自动猜测、科学符号代数。Web原型可使用较小算术子集，必须标出差异。

草稿自动保存；成功求值形成独立本地历史快照，历史保留默认30天/最多200条，用户可固定。取消当前结果只隐藏结果，不删除已存在的历史；清理历史不删草稿。历史重开使用当时表达式及引擎版本，重新求值形成新记录，不伪装成旧结果。

验收：`(12+8)*3 → 60`；`0.1+0.2 → 0.3`；除零不显示Infinity；负数与括号优先级正确；取消前后表达式逐字符相同；连续计算不覆盖前行；IME输入`=`不误触发；切换便笺/计算不串稿。

## C. 待办、提醒事项与 Siri

本地待办无需账户即可新建，字段只突出标题、可选日期和完成；默认列表显示今日/未完成，完成动画后条目移到已完成。复原完成操作可撤销。重复、子任务、标签等高级信息进入详细页，不把它们放满窄栏。

“连接苹果提醒事项”使用EventKit，在连接动作时申请权限。选定列表后，系统任务与本地任务有清楚但轻量的来源标记；一个任务有且只有一个权威provider。默认新任务的目标沿用上次明确选择的列表，首次默认为本地。快捷新建在当前筛选来源中工作，不悄悄把所有旧本地任务上传。

| 情况 | 正确行为 |
|---|---|
| 拒绝/撤销权限 | 本地任务可用；系统列表显示连接受限；不删除缓存或系统数据 |
| 系统任务被外部修改/删除 | EventKit变化后重取；正在编辑时检查存在与版本，冲突保留草稿 |
| 已连接但离线 | 依据EventKit实际能力提交/显示系统本地状态；不承诺云端已经同步 |
| 移到其它列表 | 明确选目标；成功后更新provider引用，重试不重复创建 |
| 关闭模块/断开连接 | 停止observer，不删系统提醒事项 |
| 同一应用命令的内部重试 | 复用持久command UUID/outbox；外部已分发但回执不明时进入uncertain，先核对，禁止盲重建 |

提供Nearpane App Intents：新增本地/所选来源待办、打开指定笔记、保存明确文本；UI与Intent进入相同命令服务。Siri的系统“提醒我…”仍由苹果处理，Nearpane从已选提醒事项列表读取；不能承诺任意一句话都直接变为Nearpane任务。中文口语、系统语言、权限未授予、后台/锁屏必须实测。日期含“明天”等相对词按用户系统时区，保存原解释与明确日期，歧义优先保留无日期草稿而非猜错提醒时间。

独立Siri调用是独立请求，不能假设平台提供跨重试稳定execution ID，不能按标题和时间窗口去重。EventKit标识变化后按来源、列表和已有快照核对；无匹配/多匹配保留unresolved状态与草稿，不自动新建替代记录。本地缓存版本不代表EventKit提供服务端CAS；写前重取后仍可能有外部并发，界面不宣称消除全部冲突。

## D. 统一文件中心与 Riftlet

### 两种生命周期，一个取用入口

文件中心是实际文件的持久收纳。拖入任意可读文件类型、目录或包均可保存，未知类型用通用图标。首期不承诺所有类型都可预览；不执行文件、不自动解压、不递归跟随未知软链接。外部软链接/不可读对象显示需选择真实来源，不能用一个坏链接宣称完成。

默认导入将文件**复制到选定的受管理目录**，拖入时显示明确“保存副本”反馈，保证原位置操作不会使文件中心丢失。用户可在设置选择“移入”，随后每次拖入显示移动语义；只有复制/校验/入库成功后才处理源文件，跨卷中断不得丢源。此选择与用户希望改变存储位置的诉求相符，但不把首次普通拖动变成隐形破坏性移动。默认复制与可选移动的取舍见ADR-NG-06。

已在对象库内的文件通过身份与事务ID去重，不额外复制。稳定下载Inbox与对象库分离时，完成下载默认复制一次入库，明确选择移入才在安全确认后处理源。两个同名文件都保留，存储用UUID路径、界面保留原名。相同字节可以按实现优化底层存储，但逻辑记录/使用时间不能被误合并。

可选“移入”在清理源前重新核验原file identity和最新内容指纹；文件包/目录用完整清单，不只看根时间戳。复制后源被修改、路径被替换或不可确认时保留原文件，显示“已保存副本，原文件保留”。清理必须可恢复、可重入并记录原位置，禁止无条件删除源路径。

### 60秒与托盘

保存完成才产生`ShelfEntry`，默认60秒后退出最近展示。只做`visible → archived`，不调用删除/移动到废纸篓。正在悬停、拖出或打开菜单的条目延后移除；重启/休眠后按时间戳处理，不重新复制。点“固定”加入常用；移出常用不删文件。

截图与通用文件在统一货架上有独立分区/页。存在待附加截图时，默认保持截图页；新文件用工具区短行提示，可点击切到文件页，不抢占截图格子。只有文件启用时，货架全部服务文件。Riftlet 仍最多两行两列、单图展开独占一行，滚轮/分页按原契约。失败截图重生、原目标草稿、不自动发送全保留。

通用文件点击默认打开预览/详情；拖出交给系统目标。只有具有明确目标和能力的“附加到…”才调用附加适配器，不把任何文件单击都盲塞进聊天框。不因为文件中心支持任意类型就宣称Riftlet每个站点都支持这些附件类型。

### 档案与目录

在既有主窗口增加文件档案：最近、常用、全部；按名称/类型/日期搜索，返回原文件及状态。首期内容全文索引默认不采集，避免为方便搜索扫描所有隐私文档。取用操作有打开、拖出、重新展示、在Finder显示、复制、明确删除；删除文字写“移到废纸篓”，与“从托盘收起”分开。

默认目录使用当前产品用户数据容器内的Files子目录；用户可选择自己可见的普通目录。界面始终提供“在Finder打开文件中心”。变更目录时展示文件数量和预计空间，执行可恢复迁移；外盘/iCloud占位未就绪时显示连接/下载状态，不先标保存成功。授权书签失效只请求该目录，不申请无关全盘权限。

### 下载集中

提供“设为下载收件目录”的一次性指导：打开当前浏览器的标准下载设置，用户选择稳定Inbox。该目录与可迁移对象库独立，修改文件保存根不改变浏览器正在写入的路径，界面分别显示“文件保存位置”和“下载收件位置”。这增加默认副本占用，但避免迁移后浏览器继续写旧目录而丢失观察；选择安全移入可减少副本。Safari、Chrome官方支持改目录；Edge等在实际版本验证后再列入支持。Nearpane本轮不直接改浏览器配置、数据库或全局下载偏好。

用户也可授权观察已有Downloads目录，此时只观察选定来源。过滤`.crdownload`、`.download`等中间文件，处理完成重命名/文件promise与可读状态；未知完成状态继续等待，不把短暂大小稳定当下载完成证据。导入去重、循环观察与目录迁移必须测；未完成下载永不抢移。

## E. 剪贴板

### 默认与显示

模块默认关闭。用户选择开启后才观察剪贴板变更，并处理系统的ask/allow/deny状态；不通过反复读取触发连续权限弹窗。开启自动展示不等于永久保存历史。默认只保留当前会话的最近片段（内存最多20项、锁屏/退出清理），提示6秒后退出。用户启用历史时默认7天/最多100项，另有固定与清空；不默认上传。

文本以两行摘要、图片按Fit、文件以类型/名称呈现。用户主动启用自动展示后，**未分类的普通文本允许在本机显示摘要**；来源未知只隐藏来源标签，不一律遮掉正文。已知敏感内容跳过采集，隐私隐藏模式对其余内容只显示类型、由用户点击揭示。秘密来源、密码管理器标记及安全字段尽量排除，但不能宣传100%自动识别密码。提供菜单栏暂停收集、排除应用和隐私隐藏。读取全局clipboard不能可靠证明来源应用，originConfidence与sensitivity分别记录；observedAppHint只用于保守排除，不能作为“此内容安全”的证明。

### 一次点击原目标

正常路径：用户在外部输入框工作 → 复制内容（来源可在另一App） → 返回目标输入框 → 点击Nearpane片段 → 非激活表面冻结该目标 → 验证 → 写入选区 → 收到可确认回执。点击不等于发送，不触发Return，不自动提交表单。

目标必须按[架构](architecture-data-model.md)的InputTargetLease核验。用户切到另一个窗口/网页、目标关闭、权限被撤销、密码框、不可观测或只有整段覆盖能力时，显示“无法确认输入位置”并给“复制”。不静默使用CGEvent快捷键、恢复一个猜测的App、寻找另一个输入框。

有写入尝试但无证据时显示“尚未确认插入，请检查输入框”，保留内容；不自动重试以免重复输入。已确认时短反馈“已插入”，按当前片段展示策略收纳，不删除用户主动固定的历史。

## F. 翻译与语言笔记

主要入口是侧栏语言页“翻译所选”、系统右键Services或把明确文字拖入语言页，不要求全局快捷键。用户选择文字后不会无条件弹大框或自动向云发送。AX读取不可用时提供“复制后翻译”或手动粘贴，不能承诺所有App的选区都可读取。

语言页显示原文、译文、备注三个独立部分。默认自动识别源语言、目标沿用用户选择；没有模型时只有一个清楚的“下载语言”动作。系统本地Apple Translation作为默认适配器，先查语言支持与已安装模型；离线模型不可用/不支持语种时保留原文，允许用户明确选择云端。不能静默降级到云。

云端采用提供方适配器，凭据在Keychain；发送前用户已选服务且该动作只传当前原文，不发送整份语音、文件历史或窗口上下文。质量判断使用中英日常、产品术语和学术样本，不因为“本地”就宣称最好。提供方错误/限额不会覆盖上次译文，展示请求来源和失败状态。

翻译结果只是当前稿；用户点“保存语言笔记”才保存原文、译文、备注、来源、语言与provider版本。编辑原文后旧译文标“需更新”，不当场自动改写用户已修订译文。选区译文可明确复制或使用同一目标服务插入，失败回退同剪贴板。

学习资料首期支持标签/备注/词句收藏及来源链接，不默认生成课程、复习提醒、评分或自动同步到普通便笺。来源被删时语言笔记保留自己的副本。

## G. 音乐与播客

### 显示原则

媒体模块启用后，有可靠播放信息才出现。歌词可用时默认显示当前一到两行；没有歌词时显示曲名/作者，不伪造歌词或长期显示“加载中”。悬停或键盘聚焦时在同一高度显示播放/暂停与上一首/下一首；VoiceOver/菜单提供同等动作。能力缺失的控件不显示。

播客展示节目名、可靠章节、进度与继续播放；已有时间轴才显示快退15秒/快进30秒，已有rate能力才显示倍速。没有官方逐字稿来源不生成假字幕；明确“保存这一刻”可把节目与时间点加入自己的笔记。

### 适配器裁决

| 服务 | 本轮设计路线 | 不得承诺 |
|---|---|---|
| Music.app | 在真实Mac读取应用脚本字典，核验Apple Events的metadata/transport/seek能力；按需请求自动化权限 | 不能把MusicKit的SystemMusicPlayer当原生macOS现成全局控制器 |
| Apple Music歌词 | 来自实际有权、已可取得的接口/用户LRC时展示，标来源与时间轴 | `hasLyrics=true`不等于拿到歌词，不能保证所有订阅歌曲歌词 |
| QQ音乐 | 检查实际安装版官方公开/脚本能力，逐项填能力矩阵 | 本轮没有可确认的完整官方API契约，不展示假成功控制 |
| Apple Podcasts/其它播客 | 逐应用检查metadata/transport/time；有能力再显示章节/进度 | 系统App自身有字幕不等于第三方可以读取 |
| 无可靠适配器 | 只提供打开用户所选播放器的入口；保持模块收纳 | 不使用私有MediaRemote冒充稳定通用接口 |

当前播放器选择：有多个活动来源时采用用户上次明确选择的provider；未选时给一次简短选择，不向多个App同时广播暂停/跳曲。停止/拒绝自动化权限后退回“打开播放器”，不会影响语音输入。播放器重启使旧sessionID失效，旧位置不继续前进。

## H. 所有模块共同的完成条件

- 单独开启即有用，单独关闭停止采集与网络；关闭不删数据。
- 每域都有空态、加载、离线/拒绝、错误、恢复、重启路径；不能只做满数据演示。
- 每项外部动作分清设计、代码、替身测试、真实目标回执。
- 模块之间的内容传递必须是明确复制/引用/导出；不能以“统一”为理由共用可变正文。
- 中文14pt、键盘/VoiceOver、大字号、深色/降低透明度均需验收；悬停动作有非悬停入口。
