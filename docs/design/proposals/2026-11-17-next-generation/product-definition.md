# 01 · 下一代产品定义

## 1. 产品承诺

**Nearpane 是贴在 Mac 桌面边缘的常驻交互层：让用户在原工作现场表达、暂存、记录、取用内容，并理解和调度真实桌面。**

产品的中心是“降低开始操作的成本”。用户先说话、先记下一句、先放进一个文件，随后再决定如何处理。无需先打开目标应用、选择输出方式或记住全局快捷键。鼠标、触控板和系统语音入口能完成主要路径；标准编辑快捷键与辅助功能仍保留。

核心原则：

- 整体默认约本屏逻辑宽度的 1/8；在 1280 pt 屏幕上约 160 pt，在 1920 pt 上约 240 pt。物理 4K 像素数不直接决定控件大小。
- 完整侧栏无标题、Logo、产品名和常驻顶部工具栏；使用正式视觉 V2 的玻璃层次、等宽留白、柔和边界与紫色强调。
- 持久空间入口不能被临时内容推走或盖住。几何真实性、目标正确性和数据完整性优先于画面填满。
- 启用、显示、固定、展开、授权是不同状态。用户可以只用笔记、只用文件或只用空间，不必开启麦克风、截图与其它模块。
- Saytile 保持一份连续、可编辑、忠实的文字流；Riftlet 保持目标草稿、点击附加、开始吞噬、失败恢复、不自动发送等领域语义。
- 不把同一内容自动散播到所有模块，不把笔记、音频、剪贴板送到默认云端，不复制一套已存在的系统提醒事项权威库。

## 2. 信息架构：三个层级、四类表面

### 2.1 桌面侧栏：当前工作

**上方工作区**按用户选择组成，只有它的内部内容随工具滚动。模块按四类呈现：

| 表面 | 承载能力 | 视觉与操作 |
|---|---|---|
| 连续输入表面 | Saytile | 连续文本，复制与状态两项主要控件；不与笔记混为一份文档 |
| 工作页 | 便笺 / 计算 / 待办 / 语言 | 同一个编辑框架，一次主要展示一个选中的数据空间；其它可作为简短摘要固定 |
| 取用货架 | Riftlet 截图 / 通用文件 | 截图保留原 2×2；通用文件有独立最近展示、常用与档案入口 |
| 临时或环境行 | 剪贴板 / 音乐或播客 / 时钟 | 单行或两行、低控制密度；没有内容时不留空白卡片 |

**下方空间区**保持自己的滚动和锚点。默认显示有证据的真实 Native Spaces；未知归属显示真实可见窗口及受限状态。已有 Virtual 模式单独标识和验收，本轮不删掉历史目标，也不把它包装成原生 Spaces。

三圆角的旧式固定功能分区改为最多三种视觉层：外壳、工作内容表面、空间表面。内部主要使用留白和细分隔，不为每个新能力生成一张彩色背景卡片。

### 2.2 主窗口：档案与较长操作

扩展 P5.12 的现有主窗口，统一导航包含语音、截图、文件、便笺、计算、待办和语言；剪贴板历史仅在用户启用后出现。搜索按当前领域执行，可以由用户明确选择“全部已启用档案”；敏感剪贴板不自动进入跨域搜索。

侧栏适合当前条目、快速输入、查看结果。长文、复杂公式、完整文件历史、列表筛选、音频回听和批量管理进入同一个主窗口。打开主窗口不会复制新数据，也不会停止侧栏服务。

### 2.3 设置：少量默认，完整高级

常规设置只突出五组：**模块、显示器与布局、数据与存储、连接与权限、外观**。首次使用不要求填完所有设置。

- 模块：是否启用、是否常驻、顺序；拖动或上下按钮都能调整。
- 显示器与布局：主驻留屏、边缘、自动/手动分配、Docked/Floating。旧尺寸、字体、透明度与精确参数放“高级”，值和恢复范围都保留。
- 数据与存储：实际文件目录、档案保留、导出与清理。每域独立。
- 连接与权限：仅显示已选择模块的连接和真正需要的权限。
- 外观：跟随系统、推荐玻璃层次、降低透明度；精细玻璃调节继续放高级。

主界面通过菜单栏或上下文菜单进入配置，不放长期占位的设置栏。提供可发现的首次轻提示；所有鼠标操作也有菜单/VoiceOver 等效动作，悬停不是唯一入口。

## 3. 默认与自定义

### 新安装

默认组合继续是 Saytile、Riftlet、Spaces，使用新的自动布局。麦克风在用户首次启用收音时请求；剪贴板、云翻译、播放器控制不默认开启。默认界面让用户立即理解原有核心能力；新功能从同一模块选择页一步加入。

仅有一份工作页时不出现多余切换条。两份及以上使用紧凑的类型选择器：便笺 / 计算 / 待办 / 语言，宽度不足时显示当前名称及菜单，不能把四个短标签挤成无法点击的小格。

### 已安装用户

仅旧布局字段缺失、没有显式覆盖记录时可迁移为自动；任意显式保存的布局键，即使数值恰等于出厂值，仍保留为“自定布局”。迁移不得重写其它屏幕、透明度、字体、模块启用状态或领域库。用户选择“采用自适应布局”时保存旧快照，支持一键恢复。无需每项参数重新确认。

### 任意组合

| 启用组合 | 侧栏行为 |
|---|---|
| 只开一个本地模块 | 整个工作区服务该模块，不显示 Spaces 空壳或麦克风请求 |
| 默认三核心 | 语音、截图、真实空间；大小由内容与空间数量自动预算 |
| 四至六个能力 | 一个主工作页、一个或多个短摘要、既有采集表面与货架；工具内部滚动 |
| 全部能力 | 仍只有一个主要编辑页；语言/计算/待办切换保留各自草稿；临时行不会新增外层卡片 |
| 只用 Spaces | 工具区完全消失，空间区使用完整可用高度 |
| 全关 | 侧栏隐藏，菜单栏可重新启用；不新建虚假内容，也不继续后台采集 |

“功能可独立运行”指同一 Host 内每个模块单独可用和可停用，不承诺首期把每个新增模块发布成独立 App。Saytile 与 Riftlet 现有独立产品继续保持。

## 4. 常驻与临时

- **常驻**是稳定入口、持续草稿或当前队列；无需新的事件才能出现。
- **临时展示**是新文件或剪贴板的可取用提醒；它的消失不等于原数据删除。
- **固定**只延长展示寿命；不偷偷改变采集/上传策略。
- **展开**是用户正在处理某项内容。最多一个工作页取得详细编辑焦点；原有语音/截图领域并不因此停用。
- **关闭模块**停止其观察器、定时器、网络和采集；数据保留，除非用户另外执行明确清理。关闭语音立即停止新音频采集并解除订阅，再排空已接收片段的本地写入；不等待云请求结束才关闭麦克风，未完成处理保持可恢复。

## 5. 跨模块协作

只在明确动作后传递选定内容。例如语音选区“存为便笺”、文字“新建待办”、文件“附在便笺”、翻译结果“保存语言笔记”。默认是创建目标域的独立副本或可失效引用，源数据保持原样。源记录删除后不会连带删除目标副本。

不提供“一键让所有模块理解全部桌面”的隐形共享开关。统一搜索不等于共享写权限，统一视觉不等于统一数据库。

## 6. 范围裁决

本阶段交付完整本地笔记/计算/文件基础，连接提醒事项、有限目标插入、本地翻译以及按实际能力工作的媒体行。日历/天气/AI 助手保留现有扩展点，本轮不扩成新项目。公开第三方插件市场、账号云同步、全应用无障碍插入、全播放器歌词、自动替换系统 Spaces 均不作为本轮开发完成条件。

支持能力受限并不意味着在产品里留下失效按钮：能提供原生入口时显示“在提醒事项打开”“打开播放器”“复制”，缺少数据时保持安静。技术限制和诊断留在详情，不把工程字段写满消费界面。

本文件全部为 **Designed**；现有实现及已验证范围见 [基线审计](baseline-audit.md)。
