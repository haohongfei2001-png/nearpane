# 06 · Codex 分阶段开发任务与验收

## 0. 使命与执行边界

把本设计实现为隔离的下一代 Nearpane 候选。实施者负责设计理解、代码、迁移、构建、回归、修复和持续提交；用户不承担任务协调、重复手工搬运指令或充当默认测试员。

本设计PR仅交付规格与原型，不包含原生开发。开始实施时从**最新原生实现分支**创建新的实现分支，读取其AGENTS（若存在）、当前状态、域锁与本设计；不能从只有官网的main开始重写应用。检查是否已有人继续提交，记录和本次最终固定`beeccbaa80ea1239042338b48cf5f53011a74c22`的差异，再应用设计。保持用户工作树及旧安装包不变，必要时独立worktree、bundleID和测试容器。

默认沿推荐方案执行，不反复询问颜色、常规控件、文件命名等问题。真实权限、私人会话或不可获取设备造成阻塞时记录所缺内容，暂停**该能力**并继续其它任务。不要用测试替身绕过系统准入，也不要卡在一个第三方集成上无限研究。

## 1. 状态与交付标准

每个任务记录 `Designed / Implemented / Validated` 三列，而不是用一个DONE覆盖全部。验证还标 `unit / fixture / web / native / external-service` 范围。测试数量不能作为真实录音、系统Spaces切换、输入目标或上传终态的替代证据。

每阶段交付：可复核commit、改动和理由、针对该阶段的验证、剩余风险、下一阶段入口。更新单一进度文件 `engineering/verification/NEXT-GENERATION-STATUS.md`，不要同时维护互相矛盾的十份总状态。记录失败用例和重现方式，修复后复验相关路径；必要门槛通过后停止无限扩大测试。

## 3. 阶段0：准确基线

### NG-00 / P0

输入：本目录、最新implementation head、PRODUCT_COMPLETION_STATE、视觉V2/原图、ADR-010—013、domains.lock、PR #7—#9。

动作：

- 固定源码、签名包来源和域版本；明确本轮最新GitHub head不一定等于个人已安装包源码。
- 比较旧PR与当前head。按单个有价值改动裁决移植/已被替代/不采用，禁止全分支覆盖Saytile 0.18与新档案。
- 将旧配置/库复制到独立验收容器；记录数据量与digest，不能在产品正式库直接试迁移。
- 建立能力表：当前Spaces/普通窗/手动插入/附加的真实准入沿用；新功能全部从Designed开始。
- 纳入最终基线新增的会话可用性、可撤销窗口快照、普通窗用户布局、选定controller规则与更新重启活动检查；P5.14受限自建窗口证据不能扩写为生产Host端到端通过。

验收：新候选可独立启动，原安装与数据未变；差异记录能说明当前源、目标、旧PR处理。若不能构建，先修复真实基础构建问题，不能拿静态HTML冒充原生产品。

## 4. 阶段1：布局与Host

### NG-10 自适应LayoutEngine

从`Sources/NearpaneCore/Layout.swift`与`DisplayPresentation.swift`迁移，遵循布局规格的最低/偏好尺寸与分配顺序；取消可选模块覆盖Spaces的组合。工具视口和空间列表独立滚动；实现结构变化epoch、当前空间锚、拖动结束提交、用户手动边界和双击恢复。

验收：0/1/3/6/全部模块，0/1/2/4/5/8/16空间与1280×800、1440×900、1920×1080；无负高、重叠热区、横向溢出；语音/新文件连续20次更新时空间边界变化0pt；手动模式不被新内容重置。切页、展开、收起保留光标/IME和滚动位置。

### NG-11 生命周期与内容传递

扩展`Modules.swift`正交状态，复用现有instance/revision/epoch机制；内容传递只能由明确命令触发，domain store保持独立。启用/停用、隐藏、固定和展开不混用。

验收：只开笔记不启动音频/截图/AX；关闭clipboard观察器计数归零；隐藏voice继续既定收音；明确关闭voice立即停止新采集且已接收片段入库。旧epoch回调不能更新新草稿；一个领域异常不清空其它域。

### NG-12 主窗口与设置

扩展P5.12 `SettingsView.swift`及现有档案导航，而非另建设置产品。五组常规设置，旧精调放高级；只有已启用功能申请对应权限。完整侧栏无品牌Header，采用正式V2玻璃/原图Fit；菜单与VoiceOver覆盖悬停动作。

验收：新领域档案入口引用同一记录；没有重复语音/截图库；初次拒绝权限不阻止本地笔记使用。恢复单屏某项默认不改其它屏或其它高级值。

### NG-13 配置与数据兼容

新布局用可版本化附属配置，保持旧HostConfiguration兼容；保留raw旧快照，不往旧枚举字典写未知项。

必须通过：

1. `measures={}`且glass=nil可自动迁移。
2. 显式`voiceHeight=22.5%`即使与factory相同仍保留。
3. `panelWidth=20pt`、`reservedWidth=119pt`，临时展开不改119。
4. 另一屏左侧/Floating/主动隐藏不被覆盖。
5. 新→旧→新，新模块顺序、草稿、显式/nil与pt/%语义恢复，旧版不会因schema崩溃。

## 5. 阶段2：工作页与本地领域

### NG-20 便笺与编辑器

实现NoteStore、自动保存/journal、主窗口档案、轻量文本/清单/文件引用、选区命令。长文与中文IME要用真实TextKit编辑状态验证，不每次SwiftUI刷新重建编辑器。

验收：写到一半强制终止后重开恢复最近已接收输入；切四种工作页不串文档；保存失败仍可导出当前稿；删除/恢复不会丢文件引用或改动源域。

### NG-21 计算

实现确定性本地解析器、非破坏结果、取消、明确保留等式、连续计算、草稿/历史。遵循module-specifications范围；不引入在线LLM做算术。

验收：括号/负数/优先级、小数0.1+0.2、除零、极长/深嵌套/溢出、未知符号、取消后原式逐字符一致、history不污染notes、结果继续新行。引擎版本与canonical值可追溯。

### NG-22 本地待办

实现LocalTask独立库、添加/编辑/完成/撤销、今日/未完成/已完成、可选日期与时区；不使用sample模块ID。

验收：无EventKit权限完整可用；日期跨时区按明确日期语义展示；关闭重开不重复或丢任务。

### NG-23 跨模块与搜索

实现明确选区存便笺/建待办/提交翻译等ActionBroker协议；档案当前域搜索与显式跨域选择。

验收：语音选区→笔记只复制所选内容；源删除不删目标文本；重复同一transfer幂等；clipboard敏感历史不默认进全域搜索；禁用目标域不给假成功。

## 6. 阶段3：文件中心

### NG-30 字节持久化与安全导入

实现FileStore、managed copy/move、FilePromise、目录与包、UTType、唯一存储路径、事务journal、校验后成功状态。外部引用独立标识，不能只存路径作为永久保存。

验收：原路径改名/移走后managedCopy仍可打开；copy失败、无空间、权限撤销、跨卷中断、同名、重复事件、iCloud占位、符号链接各有正确回退；复制完成到源清理之间再次修改/替换源文件与中途崩溃时保留源、不误删，移动步骤可恢复。

### NG-31 展示与Riftlet隔离

60秒从成功提交起，退出的是ShelfEntry；固定/最近/常用/历史、重新取用、用户操作时延后收纳；保留Riftlet 2×2、单图展开、失败恢复与不发送。

验收：模拟与真实计时60秒后文件字节digest不变且档案可打开；重启后仍可取；失败/待附加截图不因TTL消失；通用文件到来不抢走当前截图页。

### NG-32 目录更改

security-scoped root、迁移预检/进度/恢复；索引与字节独立原子提交；外盘离线可重连。

验收：迁移每个关键步骤故障注入后至少保有一份可核验完整数据；old root保留到新root验证；符号路径/权限变化不绕过授权；旧库与正式用户库不参与试验。

### NG-33 下载收件

提供浏览器改目录的一次设置指导、授权目录观察与完成判断、去重与循环阻断；不静默修改浏览器偏好。

验收：Chrome/Safari实际下载完成重命名只入库一次；慢下载/断网继续下载不被抢移；已在对象库不额外复制；稳定Inbox到对象库默认只复制一次；对象库迁移时浏览器继续写Inbox仍能被正确接收；不明状态等待而不是猜完成。

## 7. 阶段4：系统待办与Siri

### NG-40 EventKit provider

实现授权、列表选择、权威记录链接、变更重取、冲突草稿、拒绝/撤销路径。外部标识不保证永久稳定；重关联不得盲目新建任务。

验收：在macOS产品最低/当前支持版本完成授权与拒绝；在苹果提醒事项编辑后Nearpane正确更新；Nearpane完成后系统记录同样完成；断开不删系统记录；不把系统本地提交说成iCloud云端终态。

### NG-41 App Intents

暴露明确Nearpane动作，复用同一命令服务与应用持久command UUID/outbox，处理系统语言与权限。不得假设平台提供稳定execution ID。模拟EventKit已保存但本地回执未落盘时崩溃：恢复进入uncertain，核对前不能再次新建；独立Siri新调用仍是独立请求。

验收：中文Siri新增一次只生成一条，首次未授权能返回明确下一步；权限拒绝不绕过；后台/锁屏实际支持情况入表。若无可用真人Siri会话，交付实现+本地intent验证，真实Siri标NOT_RUN并继续其它阶段。

## 8. 阶段5：剪贴板与语言

### NG-50 剪贴板展示/历史

按主动启用、访问行为、内存/加密历史、排除/暂停/清理设计实现。44pt提示带仅在模块启用时分配；事件不覆盖编辑器。

验收：deny/ask/allow不产生权限风暴；退出/锁屏会话清理；历史关闭不持久化；保留期限与清空处理索引/缓存/WAL；日志无正文。

### NG-51 目标识别与精准插入

从NearpaneManualInsertion抽取共用证据层，保留各域动作限制。先做有限支持清单，目标不明回退复制，不加默认CGEvent盲粘贴。

原生验证矩阵：NSTextView、Safari、Chrome、Edge、至少一个Electron输入框；每类包含同App多窗、网页换页、目标关闭、选区改变、IME、安全字段、权限撤销、可能已写入但回读失败。只能对逐项真实通过的目标标支持。0错目标写入，0自动发送；无法确认的写入不重试，不假标成功。

### NG-52 本地/云翻译

实现Apple Translation适配、支持/下载检查、明确云provider选择与凭据管理；译文与原文版本绑定。

验收：支持/不支持语言、模型未安装、下载拒绝、离线、云错误、请求竞态。旧结果不能覆盖新原文；失败不改原文；未明确选云时网络审计无外发。记录至少20条同一中英样本比较，不按速度或本地标签单独宣称质量最佳。

### NG-53 语言笔记

实现原文/译文/备注/来源独立存储、修订、搜索与导出；明确保存才写语言档案。

验收：临时翻译不自动生成永久记录；保存后普通便笺/语音不被改写；已人工修订译文不被自动覆盖；来源删掉后副本仍在。

## 9. 阶段6：媒体

### NG-60 能力契约与真实探针

逐播放器记录bundle/version、公开文档或实际sdef、所需entitlement/TCC、metadata/transport/seek/rate/lyrics/chapters/transcript支持情况。禁止仅凭MPNowPlayingInfoCenter、hasLyrics或私有MediaRemote就标成功。

限定研究预算：每个provider先做一个可复现的官方/脚本探针；若没有可靠能力，交付“打开播放器”降级和BLOCKED原因，继续其它provider与模块。不能连续几轮重复探针冒充推进。

### NG-61 Music.app与媒体行

公开/脚本能力成立才接metadata与controls；多个来源显式选择；有权歌词默认一至两行，悬停/焦点控制不增高。

验收：真实播放/暂停/换歌、拒绝权限、退出/重启、离线、无歌词、有本地LRC；控制只作用于选定App，未接入不得呈现虚假进度。

### NG-62 QQ音乐与播客

QQ按实际能力分级；播客采用节目/章节/时间而非歌词；没有可读进度不生成假时间点。完成标准是可靠能力+诚实降级，不是伪造全功能支持。

验收：能力矩阵每格对应证据或NOT_RUN/BLOCKED；播放器不可用时模块可收纳且不影响录音。不得使用未获得的第三方私有接口作为默认发布依赖。

## 10. 阶段7：整体质量

### NG-70 视觉/可访问性

从本包四张设计图及HTML状态实现原生视觉，保存实际原生截图作对照；不把SVG静态设计图当实机证据。按1280/1440/1920逻辑尺寸、1×/2×、浅/深色、降低透明度/增强对比度、大字号、VoiceOver逐项检查。正文对比≥4.5:1，焦点可见，悬停有菜单等效。

### NG-71 核心不退化

原生Spaces与窗口写入仍守原准入；A→B→A未验证时入口不被新布局顺手解锁。Saytile连续表达/忠实文本/手改保护；Riftlet点击附加/吞噬/失败恢复/不自动发送；WorkRect、原生全屏、用户Hide、退出恢复按旧契约回归。无权限情况下各本地模块照常可用。

同时回归`beeccbaa`已实现的保护：锁屏/睡眠/拓扑变化挂起与新快照恢复；所选窗口60秒静态快照的身份失效/撤权/隐藏清除；普通窗用户自定布局、交换与正常Quit保留意图；规则跟随所选live controller。更新实际终止前必须重核当前录音/识别/回听、截图/附加和窗口恢复活动。新文件导入/目录迁移/草稿flush应接入同一活动闸门，不能由新模块绕开重启保护；持久UNKNOWN不等于仍在活跃上传。

### NG-72 性能与持久性

以P5.13同机同工作量为对照记录：空闲CPU/内存、连续语音、批量100文件、1000记录搜索、面板拖动帧时间与持续能耗。新本地模块空闲不得持续轮询磁盘/网络；无媒体/无剪贴板时相关观察开销为零。目标：常规操作可感反馈≤100ms、交互动画不长任务阻塞、导入及索引可取消且不主线程阻塞。性能数字是待测目标，报告真实设备/样本，不用脱离环境绝对宣称。

### NG-73 完整候选交付

在已授权开发环境独立构建/签名候选，保留旧版本；交付原生截图、版本/commit/digest、迁移与回退说明、能力矩阵及Remaining Blockers。真实通过的标Validated，只有代码的标Implemented；没有设备的标NOT_RUN。创建实现PR，别直接覆盖main、发布公开版本或自动合并本设计PR。
