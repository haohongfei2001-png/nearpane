# 02 · 侧栏布局与交互规范

## 1. 几何与视觉

全部尺寸按 macOS 逻辑 pt，渲染再乘 backingScale。完整形态默认宽度为该屏可用宽度的 12.5%，默认采用右边缘；已有左侧或精确尺寸保留。20×20 pt 图标形态继续可用，160 pt 是新默认内容的可读参考值，**不是把旧用户宽度钳成 160 的硬下限**。窄于可读范围先进入收纳形态，不把字体压小来硬塞。

外壳沿用 V2：四边相等留白，默认按宽度自适应 2–8 pt；外框比内层更实；内外圆角按间距同心；边缘亮线不超过一个物理像素。正文默认 14 pt 苹方或系统文字，行高约 20 pt；辅助文字 11–12 pt；核心按钮建议 28–32 pt 命中范围。文字、缩略图与控件不跟着玻璃变透明。紫色只用于当前项、状态与明确动作。

背景截图使用 Fit，真实桌面/窗口统一映射。容器尺寸变化不能把截图裁成强制方形、把空间内容重排成理想布局或让小窗口假装占满。

## 2. 自适应预算算法（规范性行为）

输入为可用内高 `H`、内宽 `W`、显示器真实桌面矩形、启用/常驻模块、当前编辑模块、Space 数量、用户手动值。外部可用区域扣除系统菜单栏、Dock 与安全区域，不能把硬件像素当逻辑点。

工具模块声明三种尺寸：`minViewport`、`preferredFootprint`、`expandedFootprint`。其中 footprint 是子表面的内容尺寸；工具区视口缩小只产生滚动，不直接压缩语音字体或截图。

初始参考 footprint：语音 144 pt；主要工作页 196 pt；双列截图货架 120 pt；文件短行 44 pt；媒体 48 pt；被固定的折叠摘要 28 pt。以上是设计起始值，文字放大与用户现有精调高于默认，不能用它们宣称所有屏都不滚动。

空间行可用内容高按桌面宽高比推导，容器默认在 72–144 pt 之间；内容在容器内统一 Fit。纵向屏使用留白而非拉伸。正常首屏偏好最多 4 行，第 5 行在空间余量允许时完整展示；更多行进入空间区自身滚动。

确定性分配顺序：

1. 某区没有启用能力时，高度及两区间距置零。空间读取被拒绝时只保留一条受限状态，不假造多行。
2. 两区都有内容时，工具视口下限为当前可操作表面的最低需求（默认 144 pt）；空间下限为一个可辨认行及其边距（默认不低于 96 pt）。
3. `Tpreferred` 为常驻 footprint 与内部间距之和；`Spreferred` 为最多四行的自然高度。先满足两区下限，再按二者距离 preferred 的剩余需求比例分配余量；达到 preferred 的区退出分配，余量继续给另一方。
4. 两区都达到 preferred 后，先完整显示第 5 个空间（若存在），余量交给工作区视口；子模块不为了填满余量被无限拉高，允许安静留白。
5. 所需最小高度仍大于 H 时，先将非当前摘要与媒体收纳、工具视口独立滚动；若一个可用编辑框和一行空间仍放不下，则进入紧凑入口形态。不得出现负高度、零高不可退出界面或重叠热区。

实现采用纯函数 LayoutEngine，输入/输出带 layoutEpoch。偏好值可以根据原生截图校准，但算法次序、稳定性与下限语义不能由各模块各自改写。

### 稳定性约束

自动分配只在**结构变化**时重算：用户增加/关闭/固定模块、已确认 Space 数量变化、屏幕/面板尺寸变化、文字尺寸变化、用户恢复自动。语音续写、下载进度、计时倒数、歌词变化、剪贴板出现不重算两区边界。正在拖动、选择文字、输入法组合、拖文件或按住鼠标时暂存重排，交互结束再一次性应用。

自动模式中新增真实 Space 可能改变预算；视口保持当前 Space 为锚，避免列表滚动跳到开头。显示器读取抖动/短暂未知不改变 Space 数，等到稳定快照确认再处理。

## 3. 手动调整与复原

两区之间是一条低对比细缝。悬停或键盘聚焦时显示可拖动柄与上下调整光标；常态不出现尺寸数字。拖动直接改变两区视口；松手才存该屏手动边界，双击或上下文菜单“自动分配”恢复自动。VoiceOver/菜单提供增减高度与恢复命令。

拖动过程中 Spaces 的底边和外壳不动，只有分界线移动；截图、窗口不拉伸。用户手动偏好按屏保存，屏幕变小临时钳到可用范围但不覆盖原偏好，回到原屏恢复。保持滚动锚、光标、IME、语音采集与上传状态。

已有“独立设置中精确输入所有尺寸”继续支持。主表面直接拖动是相对旧 V2 的明确替代提案，参见 ADR-NG-02，而非把旧实现写成错误。

## 4. 展开、收起、滚动

| 动作 | 结果 | 必须保留 |
|---|---|---|
| 展开工作页 | 该页获得工具视口主要区域，其它工具缩为短摘要或在滚动区外 | 底部 Spaces 位置、各域草稿、原滚动锚 |
| 收起 | 回到原工具组合 | 原选区与编辑点，麦克风及队列状态 |
| 长文详细编辑 | 在已有主窗口打开同一记录；窄栏保留摘要入口 | 相同 recordID，不新建副本 |
| 展开一张截图 | 沿用 Riftlet 单张独占一行、其它图顺序上移的规则 | 原比例、队列顺序、目标证据、失败恢复 |
| 工具区滚轮 | 只滚动工具内容 | 空间区不动 |
| 空间区滚轮 | 只滚动空间行 | 工具当前编辑状态不动 |
| 显式隐藏某个表面 | 保持隐藏直到用户唤出 | 不因同一内容/多窗条件自动反弹 |

通常避免两层同方向滚动：常态文本编辑区随工作区滚动；详细编辑时编辑器占工具视口，才接管内部滚动。底部空间区是明确独立边界。轨迹板惯性滚动不得从一个区穿透到另一区。

超长内容使用软换行、列表虚拟化、按需预览，不横向撑宽侧栏。长文件名保留扩展名，双行中间省略；完整名在悬停和无障碍标签可得。计算长式允许自身水平滚动/打开详细页，不改变侧栏宽度。

## 5. 临时内容的位置与时间

剪贴板模块启用时，工具区顶缘分配固定 44 pt 提示带，位于工具滚动视口上方但属于同一工具预算；最多一条，绝不遮挡正文、选区或其它操作。关闭该模块时不保留提示带，启用/关闭属于结构变化。复制事件只替换提示带内容，不重新分配区域；新条目替代旧提示，不连续堆通知。默认 6 秒后回到轻量的最近片段/历史入口，悬停、VoiceOver焦点或拖动时延后退出。历史未启用时该入口只提供当前会话数据。

通用文件默认成功保存后展示 60 秒，时间规则独立于文件记录。鼠标正在操作的条目不在指针下消失；过期可标记待退出，离开后收纳。固定条目留在“常用”。超时和重启从时间戳恢复，不删除字节。Riftlet 截图不得套用该超时。

媒体为工具末端一条安静环境行；暂停且没有近期内容可收起。普通播放更换不自动打开面板。歌词和控制在同一高度内切换，防止悬停布局跳动。

## 6. 屏幕与多屏

| 场景 | 设计要求 |
|---|---|
| 1280×800 逻辑 pt | 默认 160 pt；使用紧凑类型菜单，优先一个编辑表面；工具滚动、空间保留至少一个可读行 |
| 1440×900 | 默认 180 pt；2×2 截图与常用 2–4 空间清楚；不靠缩小字号装下全部模块 |
| 1920×1080 | 默认 240 pt；可展示更多摘要与空间；不增加常驻设置/品牌栏 |
| 超宽屏/大逻辑桌面 | 默认仍 12.5%；可在设置改窄，不私自用 300 pt 硬上限覆盖比例或用户值 |
| Retina 1×/2× | 计算逻辑 pt，边框按物理像素；检查小数坐标导致的模糊 |
| 竖屏/旋转屏 | 以该屏可用区域重算容器；Space 内容统一缩放留白，不能改变真实几何 |
| 多显示器 | 一个主驻留屏承载工具，副屏只显示该屏空间；同一 Host/同一领域实例，不能多开麦克风或复制文件队列 |
| 拔掉主驻留屏 | 临时转移到可用屏，保留原屏偏好；恢复后按明确策略归位，禁止屏外丢失窗口 |
| 原生全屏 | 默认隐藏完整侧栏/空间区，不压缩全屏窗口；只有用户允许的小入口可手动唤出工具浮层 |

**WorkRect 不跟随 UI 显隐变化。** 桌面编排仍启用时，当前屏 Docked 的持久预留只在用户应用占宽/预留宽度或切换 Docked/Floating 时改变。折叠、切换工作页、展示一分钟文件、关闭其它工具甚至隐藏完整 UI 都不能暗中拖动第三方窗口。

“隐藏空间预览”只关闭呈现，后台编排和 WorkRect 继续。“停用桌面编排”停止观察与自动管理，排空在途动作并按既有恢复契约撤销自动改动、保留用户布局意图；保留每屏预留偏好供重启使用，**停用期间不宣称能约束其它 App 的窗口**。只用笔记而不启用编排时，侧栏是浮动工作表面，不请求辅助功能。设置不得把这两项行为合并成含糊开关。

## 7. 权限、故障与易用性

权限在动作当下请求；拒绝只在相关模块内给一句可执行提示，不在每张卡片贴红色警告。未知状态不等于空记录。撤销权限立即停止读取/写入，保留本地草稿和失败动作的上下文。

继承最终原生基线的会话可用性判断：锁屏、睡眠和显示器拓扑变化时，撤销窗口快照并挂起相关桌面观察/编排；恢复须重新取得会话与身份有效的新快照，不能因屏幕点亮而直接重放旧状态。显式选择的窗口图像是一份可撤销静态快照，不能变成默认全窗口连续捕获；过期、身份或权限变化后回到有证据的几何/只读状态。

- 笔记/计算不要求麦克风、屏幕录制、辅助功能或登录。
- 文件目录离线：保留文件名与来源状态，提供重新连接/选择目录；不显示空库。
- Spaces 只读：缩略图可看，写入热区不安装；不能把“点击无响应”当禁用表达。
- 输入目标失效：显示“输入位置已变化”与“复制”，不自动切换另一个 App。
- 模块异常：该模块显示恢复入口，语音/截图/其余编辑继续；若同进程崩溃，下一启动按独立 journal 恢复，不能声称现架构已经实现进程级隔离。

默认跟随系统深浅色；降低透明度使用实色，增强对比度加强边线，减少动态效果关闭高度动画。普通展开动画建议 160–220 ms，不用于系统状态确认；数据成功回执不能由动画时长代替。

## 8. 设计验收重点

除了原型场景，原生验收必须测：0/1/3/6/全部模块，0/1/2/4/5/8/16 空间，20 pt 图标与小屏完整形态，双屏与旋转屏，长中文/emoji/IME/大字号，权限拒绝与撤销，手动边界恢复，工具和空间分别滚动。连续新增 20 段语音和 20 个文件时，非结构变化下 Spaces 边界的偏移必须为 **0 pt**。
