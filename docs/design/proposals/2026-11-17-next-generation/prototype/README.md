# Nearpane Next — 可操作的高保真设计原型

**状态：Designed。** 这是下一代交互提案的浏览器原型，不是 Nearpane 的原生实现、macOS 实机截图或系统能力验收。不会读取真实语音、剪贴板、桌面、Spaces、媒体、提醒事项或下载目录。

直接用浏览器打开 [index.html](index.html) 即可运行。单个 HTML 文件自包含，不需要安装依赖、启动服务器或联网。默认数据为原创演示内容；不会向云端发送数据。

## 看什么

原型外部的导航和按钮属于设计评审工具，不会进入 Nearpane 的主界面。真实侧栏仍无产品名、Logo、常驻标题或设置栏。

| 场景 | 重点 |
| --- | --- |
| 日常 | 保留语音、截图与 Spaces 的默认组合，新增能力不默认全部打开。 |
| 我的工作台 | 一个工作页承载便笺、计算、待办、语言的呈现；四类内容分开保存。文件与音乐按需常驻。 |
| 只留笔记 | 关闭其他能力后，便笺完整独立工作；没有空的截图和空间卡片。 |
| 高密度 | 8 个模拟 Spaces、多个工具。两个区域各自滚动；不为了容纳内容扭曲预览。 |
| 权限受限 | 麦克风未授权、Spaces 只读、剪贴板目标失效。保留内容和回退入口。 |

屏幕模拟有 **1280×800 / 1600×1000 / 1920×1080** 三档；侧栏依次为 **160 / 200 / 240 逻辑点**。画廊会等比缩放整个桌面，可切换“放大侧栏”局部检查。不得将画廊中的放大尺寸当作产品默认宽度。

完整可读形态以 160pt 为本提案临界。20–159pt 的既有尺寸应改用紧凑/图标形态，不覆盖旧设置。本原型用“折叠为图标”展示此类兼容行为，不提供连续窄宽拖动的假验收。

## 可以实际尝试的交互

1. **分区调整：** 悬停工具与 Spaces 间的留白才显示把手；拖动调整；双击恢复自动。键盘聚焦分隔线后可用方向键微调，Enter 恢复自动。语音追加和文件进入不触发重新分区。
2. **工作页：** 四个图标切换独立内容；编辑便笺后切到计算，再回便笺，文字仍在。右下角展开只占工具区；收起恢复此前滚动位置。
3. **计算：** 输入 `（英文括号）`、整数、小数和 `+ - × ÷`，按 `=` 计算。关闭结果只收起结果，不改原表达式；“继续计算”以结果开启下一表达式；“保存结果”留在独立历史。本原型不支持变量、百分号、单位、日期运算、财务函数或任意代码执行。使用有限语法解析器，未使用 `eval` 或 `Function`。
4. **文件：** 点击“加入文件”或拖放任意文件到文件货架。60 秒后退出最近展示；“推进60秒”可快速演示。在现有档案主窗口的文件视图中仍能找到文件，点“重新取用”再次显示；常用标记与名称/类型搜索可用。**这里只保存当前页面会话中的名称、类型、大小等元数据，不复制文件本体，不证明持久化实现。** 截图不受文件的60秒规则影响。
5. **剪贴板：** “模拟复制文本”生成一个演示片段。点击片段仅写入本页面中左侧的模拟原目标输入框。“使目标失效”后点击被阻止，显示“复制内容，手动粘贴”。只有明确点“复制”时才尝试浏览器剪贴板写入；权限不允许时如实回退。
6. **待办：** 添加、完成、恢复只作用于独立的演示待办数组。“连接 Apple 提醒事项”只是入口展示，没有伪造授权或同步。
7. **语言：** 原文、译文和备注独立。翻译按钮仅生成明确标注的演示结果，没有调用任何模型。
8. **音乐与播客：** 默认显示歌曲元信息。用“歌词 / 播客”切换：元信息 → 有权使用的原创 LRC 样例 → 节目与进度。悬停或键盘聚焦时出现控制按钮。没有假设 Apple Music 或 QQ 音乐提供歌词读取 API。
9. **配置：** 外部“组合模块”或侧栏右键打开独立配置面板；可以单独关闭每个能力。提供深色、减弱透明、折叠图标演示。关闭能力不删除内容。

## 原型与原生实现的边界

- 预览中的窗口矩形、桌面数量和空间切换全是模拟。缩略图根据显示器宽高比统一缩放；不证明 Space 归属查询、实际切换或窗口操作可靠。
- 语音控件模拟暂停和继续，不采集音频。原生开发继续复用 Saytile 自身状态和组件，不按 HTML 重新实现识别流程。
- 截图按钮不附加真实附件；没有自动发送。Riftlet 的队列、吞噬、失败重生及历史语义必须由原生集成保留。
- 浏览器原型没有跨进程焦点权限，模拟插入不能作为 AX/Apple Events 目标识别验证。
- 所有内容仅在当前页面会话内保留，刷新会重置；没有隐含的持久化、iCloud 或账户同步。
- 自动分区公式是原型展示参数，正式布局算法、最小高度、滚动策略、可访问性与多显示器行为以设计规格和原生验证为准。
- 减弱透明、深色仅验证视觉提案；并未验证 macOS 原生材质、VoiceOver 或真实 Reduce Motion 行为。

## 资源与复现

- `index.html`：自包含交互原型。
- `tokens.json`：视觉与几何 token 的替代提案，保留 V2 风格来源与冲突说明。
- `assets/*.svg` 与 `assets/*.png`：与原型内容和 token 对照的可编辑高保真设计板及其 PNG 渲染，**不是原型浏览器截图**。
- `verify-prototype.py`：待运行的行为与截图复现脚本，使用 Python Playwright 和已安装的 Chromium（可用 `NEARPANE_CHROMIUM` 指定可执行路径）；本轮受环境限制未完成浏览器执行，不是原生验收套件。
- `create-design-boards.py`：生成 4 张可编辑 SVG 设计板。PNG 使用系统 SVG 渲染库生成。

查询参数可直接打开评审状态，例如 `index.html?scene=custom&page=calc&zoom=1`、`index.html?scene=dense&theme=dark&screen=1280x800`。

## 演示与正式架构差异清单

| 项目 | 本轮视觉/交互演示 | 正式开发要求 |
| --- | --- | --- |
| 图像性质 | SVG 静态高保真稿与其 PNG 渲染 | 原生 App 的真实运行画面另行验收。 |
| 状态保存 | HTML 当前页面会话内存 | 各领域独立持久化、迁移、恢复和权限。 |
| 档案 | 文件详情覆盖模拟主窗口相同区域，表示现有档案窗口内的文件视图 | 复用现有档案主窗口，不另建竞争的文件中心。 |
| 布局 | HTML 使用简化参考公式，SVG 为指定状态的设计预算 | `layout-interactions.md` 的确定性预算算法、layoutEpoch、原生 IME/选区/焦点保留为权威。 |
| 剪贴板 | 启用时固定44pt提示带；事件替换；6秒到期回到会话最近片段入口；悬停/焦点延后 | 原生全局剪贴板策略、独立历史、敏感内容过滤、准确目标识别须真实验证；此处没有系统读取。 |
| 自定义工作页 | 只有便笺启用时没有其他类型标签；多类型才显示切换 | 按用户启用集合动态展示，绝不暗中启用其它域。 |
| 操作与权限 | 只操作原型内的模拟数据/输入框 | 不构成 macOS Spaces、AX、EventKit、媒体或第三方 App 验收。 |
| CSS/字体 | SVG 与 HTML 的视觉 token 与状态内容对齐；SVG不能证明HTML逐像素结果 | 原生14pt正文、11–12pt辅助文字、对比度、1×/2×和系统偏好单独验证。 |
