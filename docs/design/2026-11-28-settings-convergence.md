# 设置收敛：统一宽度与中性玻璃

依据 `PRODUCT_CONSTITUTION.md` §9。本记录说明本轮实现选择，不替代产品宪章，也不构成原生验收通过的声明。

## 用户界面

外观页只保留统一侧栏宽度、透明度、强调色。每个显示器上的模块共用一条宽度；用户拖动「紧凑—宽松」滑条，不再面对数值、pt/% 单位或各模块独立尺寸。正常屏幕上的范围为 220–420 个逻辑点，小屏由 `WorkbenchVisualPolicy` 收窄。控件、图片与文字并不随宽度整体缩放。

透明度只有「随系统外观」和「自定」两种选择。自定提供一条「更清晰—更通透」滑条；浅色、深色使用同一套中性玻璃层次。切换到自定不会突然采用旧版的另一组内卡/外框透明度。内容与点击目标保持不透明，系统「降低透明度」优先使用实色背景。强调色属于 Nearpane 全局，应用到所有屏幕与模块。

语音模块只保留「侧栏文字大小」的小、标准、大三档，对应内部 12/14/16 字号；Spaces 的窗口名称对应 10/11/12。截图没有额外的字体或几何配置。原先「显示样式」折叠页、圆角、留白、间距、按钮和图标尺寸、模块高度、逐项恢复默认均不再出现在管理界面。原始布局 token 可继续供实现与历史验证使用。

显示器选择、位置、适用的副屏显示行为以及原生全屏入口仍属于全局行为设置。主驻留屏与默认位置保留在「显示器与位置」，每屏覆盖明确标为「这一屏幕的位置」。模块业务配置、权限和内容资料不随这次视觉收敛删除。

## 旧偏好

`DisplaySettings.applyingWorkbenchVisualPolicy()` 是配置归一化入口。当前生效的 `measures` 仅保留 `panelWidth`、`textSize`、`labelSize`；退休的尺寸参数保存到 `retiredVisualOverrides`，不再参与绘制。旧配置只有预留宽度时，将其作为统一宽度的迁移输入；实际屏幕上再执行有效范围约束。已有字体值量化到相邻的受支持档位，原值保留于退休字段。

旧外框/内卡透明度与留白保存到 `retiredGlassOverrides`。用户明确设置的整体透明度保留，层次与几何回归当前设计。主应用启动先在内存应用迁移；下一次用户更改配置时才保存当前值与退休值。配置版本仍兼容现有资料格式，语音、截图、备忘录、歌词缓存、模块启停和排列不由此迁移改变。

## 验证范围

Nearpane 的歌词辅助页显式传入宿主当前使用的中文界面语言，复用既有 `LyricLocalization`，不修改系统语言或独立歌词应用默认值。嵌入页面只保留内部纵向节奏，水平方向统一由主窗口的 28 点边距负责，避免完整歌词、来源与校准页面来回跳动；独立辅助视图仍使用原有默认边距。

源码测试检查可见尺寸控制的权威入口、自动与自定玻璃之间的层次连续性、保存后的当前值与退休原值。Core 另行验证迁移幂等、非法值和屏幕宽度边界。最新 macOS 构建、实际主窗口截图和宽度/透明度交互证据应来自包含本次收敛修改的提交；上一候选的细项设置截图只说明旧版本状态。
