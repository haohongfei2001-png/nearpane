**打开 Nearpane**　在 Finder 双击 Nearpane，或从菜单栏选「打开 Nearpane」。主窗口左侧的「语音档案」和「截图档案」使用当前 Nearpane 资料。语音档案可按日期和文字查阅，截图档案可回看已离开托盘的截图。点档案页右上角可进入对应模块设置。左下角显示当前版本，「应用与更新」列出内置模块版本。

**通用设置**　在「通用」选择主题色，Nearpane、语音和截图控件一起生效。这里也能控制菜单栏图标。隐藏图标后，双击 Finder 中的 Nearpane，再到「通用」即可恢复。菜单中的「隐藏侧栏」只收起侧栏，录音、截图收录和窗口管理按各自设置继续运行。选择「退出 Nearpane」会正常保存并停止应用。在「显示器」指定主驻留屏，「外观与尺寸」按屏保存宽高和玻璃外观。

**推荐玻璃**　在「外观与尺寸」选择显示器，找到「玻璃外观」。新安装使用随系统切换的推荐透明度，外框更实，正文和截图卡片更透。要从自定义透明度切回，点击「使用推荐透明度」。四边留白可单独设置或恢复自适应。

**文字和截图**　侧栏播放按钮开启收音；再次点击才会暂停。复制前可以直接编辑文字。「Saytile 语音设置」分别显示麦克风权限和系统默认输入设备的状态。默认使用本机识别；可暂停收音后在「Saytile 语音设置」选用 API，并分别授权两项服务。切回本机可清除该资料的 API 授权。截图托盘可单独使用。在「Riftlet 截图设置」选择系统实际保存截图的目录；其他目录和旧版资料不会自动导入。目录断开时收录会暂停。原目录恢复后，点「重新核对原截图目录」。资料库被占用时，先退出占用它的实例。

需要把当前文字插入其他应用时，先将光标留在目标输入框，再右键点侧栏的复制按钮，选择「插入当前文字」。此操作需要已有的辅助功能权限。目标变化、选区非空或无法确认写入时，侧栏会提示并停止后续插入。请先在原输入框核对结果。

**附加到草稿**　先打开要使用的 Chrome 草稿，再点击一张截图。Nearpane 不发送消息。「结果未知」表示没有可确认的最终回执，请先检查原草稿；重启不会自动补传。

**单词本**　在「设置 → 模块 → 单词本」输入原文或译文中的一部分，即可查找当前资料中保存的词条。清除搜索可查看全部记录。使用原位翻译时，如果本机语言包不可用，原文和语言方向都匹配且只有一种已存译文，气泡会标明「单词本 · 已保存的译文」。

**管理一扇窗口**　打开 Nearpane，在主窗口左栏点「窗口管理」。点击「选择窗口并预览…」，选择应用和具体窗口，核对预计位置，点击「授权所列窗口并应用布局」。单屏也可逐窗选择。只打开侧栏或查看预演时，其他应用仍使用 macOS 原有边界。

**让当前桌面自动分屏**　在 Nearpane 菜单选「窗口管理…」，点「启用本桌面自动分屏…」，核对范围后选「允许并自动分屏」。本屏这个普通桌面上符合条件的已有窗口和新窗口会一起排列。不同应用也可左右平分，Docked 侧栏保留自己的宽度。「停止自动分屏并恢复」撤销本次许可。正常退出并完成恢复后，下次打开会重新识别同一桌面和当前窗口。暂停后退出、异常终止或尚有恢复记录时，需要重新确认。

授权后可在同一进程和显示器内启用「新窗口」管理。之后打开的合格窗口会加入布局，已有兄弟窗口仍需单独选择。应用重启、失去权限或停止管理后需要重新确认范围。两窗时可以交换左右位置、调整宽度比例；移除第三窗后会恢复原两窗配置。

**当前桌面**　从 Nearpane 菜单选「显示本屏窗口总览」，或按 ⌃⌥⌘↑。工具下方从上到下列出本屏当前桌面的窗口，包括同一应用里互相遮挡的窗口。窗口增多时，预览按同一比例缩小，让所有窗口同时可见。点击一张预览可将对应窗口置前。玻璃透明度只改变背景，文字和窗口图像保持原有对比度。

**开启画面和切换**　点击窗口列表旁的权限提示。「窗口画面」使用 macOS 的「屏幕与系统音频录制」，「精确切换窗口」使用「辅助功能」。已有权限会显示「已允许」。点击所需项目的「授权…」并完成系统确认。返回后 Nearpane 会重新检查；如果 macOS 提示重新打开，请按系统提示操作。

「设置 → 本屏窗口」可以选择总览快捷键、关闭窗口画面或打开相应的系统设置。若要用 ⌃↑ 打开 Nearpane，先在系统键盘快捷键中解除原有分配，再在 Nearpane 选择该键。系统手势、触发角和调度中心键由 macOS 管理。开启「台前调度」时，其他组的窗口仍可按已确认归属列出；后台组的缩略图不能用于平铺。若希望各组窗口同时出现在工作区域，可自行在「系统设置 → 桌面与程序坞」调整台前调度。

**本屏窗口组**　点击组合卡中的窗口即可将它置前。窗口彼此重叠时，点卡片下方的组名可以从完整成员列表选择，同一应用的多扇窗口在列表中有各自的序号。右键点卡片可命名或解散窗口组，组名随当前资料保存。组内窗口按实际位置和前后顺序组合显示。「历史画面」标明有多少成员保留了最近在本屏显示的画面。关闭窗口画面、切换原生桌面或撤回权限会清除相应预览。此候选的整组隐藏与恢复尚待实机验收。

只有一块显示器时，可到「外观与尺寸」点「唤出本屏空间视图」。图标形态会临时展开，收起后回到保存的尺寸。在「窗口管理」已选定一扇窗口时，也可点「拍摄此窗的桌面预览」。拍摄使用已有的屏幕读取权限，只针对所选窗口；关闭预览可立即清除画面。

**工作区边界**　驻留面板占据的宽度和侧边留距共同构成工作区边界。若单独设置的预留宽度容不下面板，设置会说明需要调整的数值。浮动副面板保留整个可用工作区。拖动授权窗口结束后，Nearpane 核对位置并尝试把越界部分移回。快速反复越界、跨显示器、完全离屏或几何无法确认时，管理暂停并保留恢复记录。在工作区内移动窗口，停止管理时会保留最近核对过的布局。

**暂停、排除和退出**　隐藏界面不会暂停调度或释放预留宽度。「暂停」停止新的自动写入，现有布局留在原处。停止时只恢复仍可确认的窗口。若提示有待处理记录，先核对当前窗口，再按「窗口管理」的提示处理；不要删除恢复日志或反复授权。

**升级和权限**　同一 Alpha 资料只允许一个写入实例。换版前先正常退出旧版。旧资料导入和回退入口在「设置 → 模块」；它们不会延续浏览器目标、窗口授权或系统权限。语音、截图或窗口权限不足时，可在「系统设置 → 隐私与安全性」中只核对需要的项目。此开发版没有公证；不需要更改系统安全策略。

若系统开关已开，返回 Nearpane 的「本屏窗口」可重新读取当前应用的权限。macOS 如果明确提示「退出并重新打开」，请正常退出后再打开 Nearpane。窗口画面暂时读不到，也可能是屏幕已锁定或窗口状态正在变化。系统按签名身份识别应用，首次从临时签名版本换到开发者签名版本时，可能需要为新身份确认一次。

**时钟**　在「模块」启用并固定时钟。点击侧栏的时间可查看本地时间或选择一个额外时区，收起后继续使用原来的侧栏。

**反馈**　在「设置 → 应用与更新」展开「反馈与建议」，填写内容和所属模块，预览后确认发送。Nearpane 与 Riftlet 共用私有反馈中心，记录会标明产品与模块。可以查看本机反馈和服务回执，或申请删除。发送前可以选择是否附上 macOS 版本。

**应用更新**　在「设置 → 应用与更新」可选择每日检查。发现更新后，菜单栏会显示提示，点击查看并确认安装。更新前会正常退出并保存资料。当前开发版的签名发布通道尚未开放，界面会显示相应状态；已保存的每日检查偏好供正式通道就绪后使用。

**安装与运行**　在支持的 Apple Silicon Mac（macOS 26 或之后的兼容版本）上，可以从「应用程序」启动 Nearpane。窗口管理和资料导入使用 App 自带的运行环境。窗口移动需要辅助功能权限，可按窗口授权或授权当前桌面自动分屏。若设置提示内置助手缺失或损坏，请先正常退出，再换回完整的 Nearpane 安装包。个人资料保存在应用之外。

**当前边界**　侧栏只列当前屏幕和当前桌面的窗口。使用辅助功能浏览时可读取窗口在屏上的相对位置与大小。画面需要 macOS 允许读取这扇窗口；缺图时会显示轮廓或状态。打开列表不会启用自动平铺。普通窗口平铺只在通过逐窗检查并有实际兼容证据的范围内使用。

在「窗口规则」可通过系统文件选择器选中要排除的应用。针对某一扇窗口的例外，请到「窗口管理」选择仍在运行的实际窗口。更新已下载时，正在录音、附加截图或处理窗口恢复都会暂缓安装；可以稍后从「应用与更新」继续。
