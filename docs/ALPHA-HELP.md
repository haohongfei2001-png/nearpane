**第一次打开**　从菜单栏的 Nearpane 图标进入「设置」。在「显示器」选择主驻留屏，文字和截图托盘只在这一屏出现。点击收小后的应用图标可临时展开，不会改变已保存尺寸。

**文字和截图**　侧栏播放按钮开启收音；再次点击才会暂停。复制前可以直接编辑文字。「语音」分别显示麦克风权限和系统默认输入设备的状态。默认使用本机识别；可暂停收音后在「语音」选用 API，并分别授权两项服务。切回本机可清除该资料的 API 授权。截图托盘可单独使用。在「Riftlet」选择系统实际保存截图的目录；其他目录和旧版资料不会自动导入。目录断开时收录会暂停。原目录恢复后，点「重新核对原截图目录」。资料库被占用时，先退出占用它的实例。

需要把当前文字插入其他应用时，先将光标留在目标输入框，再右键点侧栏的复制按钮，选择「插入当前文字」。此操作需要已有的辅助功能权限。目标变化、选区非空或无法确认写入时，侧栏会提示并停止后续插入。请先在原输入框核对结果。

**附加到草稿**　先打开要使用的 Chrome 草稿，再点击一张截图。Nearpane 不发送消息。「结果未知」表示没有可确认的最终回执，请先检查原草稿；重启不会自动补传。

**管理一扇窗口**　在「窗口管理」选择应用和具体窗口，查看预演，再确认授权。只读预演不会移动窗口。当前实际平铺已在副屏标准窗口验证，主屏只做预演。关闭或最小化设置会丢弃当前预演选择；不会撤销已有管理。身份、显示器、最小尺寸、权限或 AX/CG 几何不可靠时会拒绝；不要激活另一扇同名窗口代替。未授权的兄弟窗口保持原样。

**暂停、排除和退出**　隐藏界面不会暂停调度或释放预留宽度。「暂停」停止新的自动写入，现有布局留在原处。停止时只恢复仍可确认的窗口。若提示有待处理记录，先核对当前窗口，再按「窗口管理」的提示处理；不要删除恢复日志或反复授权。

**升级和权限**　同一 Alpha 资料只允许一个写入实例。换版前先正常退出旧版。旧资料导入和回退入口在「设置 → 模块」；它们不会延续浏览器目标、窗口授权或系统权限。语音、截图或窗口权限不足时，可在「系统设置 → 隐私与安全性」中只核对需要的项目。此开发版没有公证；不需要更改系统安全策略。

**时钟**　在「模块」启用并固定时钟。点击侧栏的时间可查看本地时间或选择一个额外时区，收起后继续使用原来的侧栏。

**安装与运行**　在支持的 Apple Silicon Mac（macOS 26 或之后的兼容版本）上，双击 Nearpane 即可启动。窗口管理和资料导入使用 App 自带的运行环境。窗口移动仍需系统辅助功能授权和逐窗确认。若设置提示内置助手缺失或损坏，请先正常退出，再换回完整的 Nearpane 安装包；个人资料独立保存在应用之外。

**当前边界**　空间几何可以只读查看。使用辅助功能浏览预览时，可按前后顺序读取各窗口在本屏的相对位置和大小。真实 Space 切换、跨 Space 移窗和 Virtual 停放尚未开放。普通窗口平铺只在通过逐窗检查并有实际兼容证据的范围内使用。
