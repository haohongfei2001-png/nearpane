**打开 Nearpane**　在 Finder 双击 Nearpane，或从菜单栏选「打开 Nearpane」。主窗口左侧的「语音档案」和「截图档案」使用当前 Nearpane 资料。语音档案可按日期和文字查阅，截图档案可回看已离开托盘的截图。点档案页右上角可进入对应模块设置。左下角显示当前版本，「应用与更新」列出内置模块版本。

**通用设置**　在「通用」选择主题色，Nearpane、语音和截图控件一起生效。这里也能控制菜单栏图标。隐藏图标后，双击 Finder 中的 Nearpane，再到「通用」即可恢复。菜单中的「隐藏侧栏」只收起侧栏，录音、截图收录和窗口管理按各自设置继续运行。选择「退出 Nearpane」会正常保存并停止应用。在「显示器」指定主驻留屏，「外观与尺寸」按屏保存宽高和玻璃外观。

**文字和截图**　侧栏播放按钮开启收音；再次点击才会暂停。复制前可以直接编辑文字。「Saytile 语音设置」分别显示麦克风权限和系统默认输入设备的状态。默认使用本机识别；可暂停收音后在「Saytile 语音设置」选用 API，并分别授权两项服务。切回本机可清除该资料的 API 授权。截图托盘可单独使用。在「Riftlet 截图设置」选择系统实际保存截图的目录；其他目录和旧版资料不会自动导入。目录断开时收录会暂停。原目录恢复后，点「重新核对原截图目录」。资料库被占用时，先退出占用它的实例。

需要把当前文字插入其他应用时，先将光标留在目标输入框，再右键点侧栏的复制按钮，选择「插入当前文字」。此操作需要已有的辅助功能权限。目标变化、选区非空或无法确认写入时，侧栏会提示并停止后续插入。请先在原输入框核对结果。

**附加到草稿**　先打开要使用的 Chrome 草稿，再点击一张截图。Nearpane 不发送消息。「结果未知」表示没有可确认的最终回执，请先检查原草稿；重启不会自动补传。

**管理一扇窗口**　打开 Nearpane，在主窗口左栏点「窗口管理」。点击「选择窗口并预览…」，选择应用和具体窗口，核对预计位置，点击「授权所列窗口并应用布局」。单屏也可逐窗选择。只打开侧栏或查看预演时，其他应用仍使用 macOS 原有边界。

**工作区边界**　驻留面板占据的宽度和侧边留距共同构成工作区边界。若单独设置的预留宽度容不下面板，设置会说明需要调整的数值。浮动副面板保留整个可用工作区。拖动授权窗口结束后，Nearpane 核对位置并尝试把越界部分移回。快速反复越界、跨显示器、完全离屏或几何无法确认时，管理暂停并保留恢复记录。在工作区内移动窗口，停止管理时会保留最近核对过的布局。

**暂停、排除和退出**　隐藏界面不会暂停调度或释放预留宽度。「暂停」停止新的自动写入，现有布局留在原处。停止时只恢复仍可确认的窗口。若提示有待处理记录，先核对当前窗口，再按「窗口管理」的提示处理；不要删除恢复日志或反复授权。

**升级和权限**　同一 Alpha 资料只允许一个写入实例。换版前先正常退出旧版。旧资料导入和回退入口在「设置 → 模块」；它们不会延续浏览器目标、窗口授权或系统权限。语音、截图或窗口权限不足时，可在「系统设置 → 隐私与安全性」中只核对需要的项目。此开发版没有公证；不需要更改系统安全策略。

**时钟**　在「模块」启用并固定时钟。点击侧栏的时间可查看本地时间或选择一个额外时区，收起后继续使用原来的侧栏。

**反馈**　在「设置 → 应用与更新」展开「反馈与建议」，填写内容和所属模块，预览后确认发送。Nearpane 与 Riftlet 共用私有反馈中心，记录会标明产品与模块。可以查看本机反馈和服务回执，或申请删除。发送前可以选择是否附上 macOS 版本。

**应用更新**　在「设置 → 应用与更新」可选择每日检查。发现更新后，菜单栏会显示提示，点击查看并确认安装。更新前会正常退出并保存资料。当前开发版的签名发布通道尚未开放，界面会显示相应状态；已保存的每日检查偏好供正式通道就绪后使用。

**安装与运行**　在支持的 Apple Silicon Mac（macOS 26 或之后的兼容版本）上，双击 Nearpane 即可启动。窗口管理和资料导入使用 App 自带的运行环境。窗口移动仍需系统辅助功能授权和逐窗确认。若设置提示内置助手缺失或损坏，请先正常退出，再换回完整的 Nearpane 安装包；个人资料独立保存在应用之外。

**当前边界**　空间几何可以只读查看。使用辅助功能浏览预览时，可按前后顺序读取各窗口在本屏的相对位置和大小。真实 Space 切换、跨 Space 移窗和 Virtual 停放尚未开放。普通窗口平铺只在通过逐窗检查并有实际兼容证据的范围内使用。
